Fono Server API v2

Standalone speech recognition. Fetch /v1/capabilities and /v1/models to discover this server's limits, available models, and feature gates. The current server build provides CPU recognition.

All routes except /healthz require Authorization: Bearer <token>. Administrative model commands and metrics require an admin token. Keep bearer tokens in your client or local environment; this page does not collect or store them.

Recognize an audio file

curl -H "Authorization: Bearer $FONO_TOKEN" \
  -H 'Content-Type: audio/wav' --data-binary @speech.wav \
  'http://127.0.0.1:17832/v1/recognize?language=ru&timestamps=segments'

Raw audio/L16;rate=16000;channels=1 means signed big-endian 16-bit PCM. WAV and Ogg/Opus are supported as complete bodies. Use timestamps=none|segments|words and decoding=fast|accurate; the selected model must support the requested options. Timings are measured or supplied by the recognizer, never synthesized.

X-Fono-Glossary contains base64url UTF-8 JSON with an array of strings. Decoded JSON is limited to 4096 bytes; the native prompt additionally limits input to 32 terms and 896 term bytes. See per-model feature flags before sending glossary or accurate decoding.

OpenAI-compatible clients

from openai import OpenAI
client = OpenAI(base_url="http://127.0.0.1:17832/v1", api_key=token)
with open("speech.wav", "rb") as audio:
    result = client.audio.transcriptions.create(
        model="whisper:tiny", file=audio, language="ru")
print(result.text)

POST /v1/audio/transcriptions accepts multipart file, model, optional language, prompt, response_format, timestamp_granularities[] and temperature. A prompt is limited to 224 UTF-8 bytes and requires a model with initial-prompt support. Larger prompts are rejected instead of silently truncated. Formats: json, text, srt, vtt, verbose_json. Temperature from 0 through 1 is accepted and ignored. Timestamp arrays in verbose JSON use seconds; Fono recognition segments use milliseconds.

Limits, errors and cancellation

Every response carries X-Request-Id. JSON errors contain a stable code and safe message. HTTP 401 means a missing or revoked token; 403 means insufficient scope or a disabled feature; 404 means an unknown or missing model; 408 means a body reception timeout; 413 means a size or duration limit; 429 means admission is busy and includes Retry-After. A slow upload has a total reception deadline, while recognition may continue longer.

Disconnecting a synchronous recognition request cancels its operation. Native work holds admission until it actually returns. Batch jobs have an independent lifecycle and use explicit cancellation. Do not automatically repeat a request if the first operation's outcome is unknown.

Client model control is disabled by default. Enable models.client_model_load=true explicitly to use admin load/unload. Model files are installed through the server CLI; the API never downloads them. Metrics are enabled independently with metrics.enabled=true.

The default listener is loopback. For a protected private network, configure the exact Host allowlist and explicit network assertion. This build does not provide TLS. CORS grants no cross-origin browser access. Read the network contract in the source documentation before changing the bind address.
