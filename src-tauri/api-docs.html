Fono Local API

Документация локального REST-сервиса. Страница доступна только на этом компьютере.

Доступ к спецификации

Вставьте bearer-токен из %APPDATA%\Fono\api-token.txt. Он остаётся только в памяти этой вкладки и передаётся в HTTP-заголовке, не в URL.

Введите токен, чтобы посмотреть спецификацию.
