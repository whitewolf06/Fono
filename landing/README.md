# Сайт Fono

Пять статических русских страниц в стиле приложения V3. На стороне посетителя
нет Vue, UI-кита или других библиотек. Для сборки и разработки нужен только
Node.js 22 или новее. Установка npm-пакетов не требуется.

## Локальный запуск

Из корня репозитория:

```sh
npm --prefix landing run dev
```

Открыть http://127.0.0.1:1430/. HTML, стили и активы пересобираются при изменении;
обновите страницу в браузере. После изменения конфигурации или скриптов сервера
перезапустите процесс. Если npm недоступен, используйте
`node landing/scripts/dev.mjs`.

## Сборка и проверка

```sh
npm --prefix landing run build
npm --prefix landing run check
```

Эквивалент без npm: `node landing/scripts/build.mjs` и
`node landing/scripts/check.mjs`. Готовые файлы находятся в `landing/dist/`.
Проверка использует временные сборки и проверяет страницы, ссылки, SEO,
оба состояния скачивания, HTTP-статусы и отсутствие npm-зависимостей.

Для форматирования и lint используются инструменты основного репозитория:

```sh
node node_modules/prettier/bin/prettier.cjs --check "landing/**/*.{html,css,js,mjs,json,md}" --ignore-path landing/.prettierignore
node node_modules/eslint/bin/eslint.js landing --max-warnings 0
```

## Структура

- `src/pages/`: содержимое страниц в HTML; один H1 на страницу.
- `src/partials/`: инфографика диктовки, таблица возможностей и системные требования.
- `src/templates/`: общий документ, шапка, подвал и HTML-escaping.
- `src/styles/`: токены, базовые стили, сетка, компоненты и оформление страниц.
- `src/js/`: мобильная навигация; без JS меню и весь контент доступны.
- `src/assets/`: собственные копии изображений, favicon и SVG.
- `scripts/`: сборка, локальный HTTP-сервер и проверка.
- `site.config.mjs`: публичный адрес сайта и ссылка на установщик.

HTML-placeholder заменяется только во время сборки. Общие шапка и подвал
не загружаются через JavaScript. Ссылки и ресурсы относительные, поэтому
обычные страницы можно размещать в подкаталоге. CSS не импортирует стили
приложения, а сайт не входит в Tauri/Vite-сборку.

## Домен, скачивание и публикация

В `site.config.mjs` задайте `siteUrl` (например, `https://fono.example/`) и
`downloadUrl` (реальный HTTPS URL опубликованного установщика). Эти значения
можно передать через `FONO_SITE_URL` и `FONO_DOWNLOAD_URL` при сборке.
Секреты в конфигурацию не добавляются.

Без домена каждая страница получает `noindex, nofollow`, robots.txt запрещает
индексацию, sitemap и canonical не создаются. С доменом сборка формирует
canonical, абсолютные Open Graph URL, sitemap.xml и robots.txt для индексации.
Перед публикацией пересоберите сайт с реальным адресом и проверьте результат.
Наличие этих тегов не гарантирует индексацию и позиции в поиске.

Без ссылки на установщик страница скачивания сообщает о подготовке релиза и
даёт обозначенную ссылку на GitHub Releases. После задания ссылки она показывает
кнопку «Скачать бесплатно для Windows». Номер рабочей версии приложения не
публикуется автоматически: он не подтверждает доступность релиза.

Разместите содержимое `dist/` на статическом хостинге с directory index.
Настройте отсутствующие адреса на ответ HTTP 404 с `404.html`; SPA fallback на
главную не нужен. Локальный сервер уже возвращает 404. Для размещения в
подкаталоге укажите полный путь в `siteUrl`; robots.txt поисковики читают из
корня домена, поэтому его нужно разместить там или объединить с существующим.
Публикация и установка Fono не выполняются командами сайта.

Здесь нет форм, аналитики, сторонних шрифтов, записи микрофона или API-вызовов.
Волна и интерфейс на главной — иллюстрация. Голосовой ввод описывает классический
режим с результатом после завершения записи.
