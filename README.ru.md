# Fono

[English](README.md) · [Скачать для Windows x64](https://github.com/whitewolf06/Fono/releases/latest) · [Документация](docs/README.md)

Голосовой ввод для Windows с локальным распознаванием. Продиктуйте текст в нужное
поле, а при необходимости включите обработку или перевод через выбранное
LLM-подключение. Интерфейс доступен на русском и английском.

## Возможности

- Диктовка с удержанием или повторным нажатием горячей клавиши. Состояние записи
  видно в плавающем индикаторе.
- Локальный Whisper с CPU, Vulkan и CUDA; GigaAM и Parakeet на CPU.
  Модель выбирается и загружается в приложении.
- CPU и Vulkan входят в базовую поставку. Подписанный CUDA-пакет устанавливается
  отдельно из настроек аудио; Auto использует доступные backend-ы.
- **Пробуждение «Привет, Лира» — бета.** Включается вручную. Начинайте диктовку
  после сигнала готовности или появления индикатора. Задержку и качество на
  разных голосах ещё предстоит улучшать.
- Обработка текста, перевод и собственные инструкции. Для обычной диктовки
  подключение к LLM не нужно.
- Профили приложений, личный словарь, история и речевой тренер. Сохранение
  истории и разрешение на аналитику настраиваются отдельно.
- Локальный REST API для заданий распознавания и подтверждаемые голосовые команды.
- Ключи подключений хранятся в Windows Credential Manager. Облачная обработка
  отправляет текст выбранному провайдеру; локальное подключение позволяет
  обрабатывать его на своём компьютере.

Распознавание выполняется после завершения записи. Экспериментальный режим
«На лету» скрыт. Старый мастер произвольной wake-фразы остаётся выключенным;
[Лира beta](docs/wake-lira.md) работает отдельно с фиксированной фразой.

## Установка и первый запуск

1. Скачайте `FonoSetup.exe` или полный установщик Windows x64 из
   [GitHub Releases](https://github.com/whitewolf06/Fono/releases/latest).
2. Выберите микрофон и загрузите модель распознавания.
3. Настройте горячую клавишу и для первой проверки выключите обработку текста.
4. Откройте нужное поле, продиктуйте текст и отпустите клавишу либо нажмите
   сочетание повторно — в зависимости от режима.

[Руководство пользователя](docs/user-guide.md) описывает действия с результатом,
настройки, Лиру, историю, приватность и обновления. Второстепенные настройки
собраны в блоках «Дополнительно».

Проверка обновлений не запускает установку. Автоматические проверки включаются
по желанию; установка требует отдельного действия после завершения активной
работы. Версия в исходниках не означает публикацию установщика с тем же номером.

## Разработка

Frontend устанавливается из публичного npm. Точный архив WhiteUI 0.6.0 включён
в [vendor/whiteui](vendor/whiteui/README.md); npm-токен не требуется.

Для CPU dev на Windows нужны Node.js 22, закреплённый Rust toolchain, MSVC C++
Build Tools и Windows SDK, CMake, LLVM/libclang, PowerShell 7, Python 3.12+ и
WebView2. После установки зависимостей:

```powershell
npm ci
npm run dev:cpu
```

Launcher получает проверенные по хэшам native-ресурсы и создаёт отдельный
debug-профиль. Микрофон, hotkey и диктовка настоящие; credentials и автозапуск в
этом профиле недоступны. CUDA/Vulkan SDK для CPU-пути не нужны.

Для интерфейса используйте `npm run dev:ui` и
`http://127.0.0.1:1420/v3.html`. Там mock-порты и демонстрационные данные.
[Разработка и сборка](docs/development.md) описывает native dev, GPU workers и
отдельный release-пакет Лиры.
