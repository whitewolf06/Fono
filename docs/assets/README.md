# Иллюстрации интерфейса

Скриншоты созданы 17 октября 2026 года из рабочего Vue V3 на browser mock,
viewport 900×720. Использованы только встроенные демонстрационные тексты и
записи. Настоящее приложение, микрофон, горячая клавиша и внешние поля не запускались.

Название и графика приложения сохраняют [условия бренда](../brand-assets.md).
