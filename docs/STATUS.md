# Статус Fono

Обновлено 12 ноября 2026 года. Готовится [кандидат 0.9.0](releases/0.9.0.md):
Fono Server на Ubuntu и подключение Windows-клиента к его API. Версия исходников
находится в [package.json](../package.json). Последний подтверждённый публичный
выпуск — [0.8.0](releases/0.8.0.md); подготовка кандидата не означает публикацию.
Предыдущий срез сохранён в [историческом журнале](archive/status-2026-10-26.md).

## Реализовано

- Классическая диктовка с удержанием и повторным нажатием горячей клавиши,
  overlay, отменой и безопасной вставкой в исходное поле.
- Локальный Whisper на CPU/CUDA/Vulkan и офлайн GigaAM/Parakeet на CPU.
  База содержит CPU/Vulkan; CUDA-пакет устанавливается отдельно с проверкой подписи.
- [Fono Server на Ubuntu](server.md): API v2 без рабочего стола, CPU и CUDA,
  очередь и отмена заданий, управление моделями, health/readiness, расширенный
  doctor, TLS, обновление сертификатов и ограничение частоты запросов.
- [Веб-панель](server-panel.md): вход по токену, состояние, модели, очередь,
  документация и пробный запрос. [Ключи приложений](server-clients.md) выдаются
  отдельно, показываются один раз и могут быть отозваны администратором.
- [Удалённое распознавание Windows](remote-recognizer.md): переключение источника,
  HTTPS или SSH из интерфейса, проверка доступности и совместимости, выбор модели,
  сохранение записи для повтора и выбранный локальный резерв на CPU. Серверный
  источник используется и для файлов; история учитывает фактический backend.
- Компактный overlay сохраняет волну и статус во время обработки. Текст обычной
  автоматической диктовки показывается для копирования при заблокированной
  вставке; предпросмотр ограничен двумя строками. Полный текст сохраняется.
- Обработка и перевод через выбранное подключение, собственные инструкции,
  профили приложений и личный словарь. Незавершённая настройка обработки
  не блокирует обычную диктовку и вставку.
- История и отдельное согласие на аналитику, речевой тренер, варианты LLM
  для сохранённой записи, экспорт и локальный REST API.
- Русский и английский интерфейс. Основные настройки доступны сразу,
  второстепенные собраны в «Дополнительно».
- Восстановление WebView2 после сна и явные состояния ошибок.
- [«Привет, Лира» beta](wake-lira.md): отдельный opt-in детектор, сигнал
  готовности, повторные пробуждения и очистка фразы перед вставкой.
  Переносимый runtime включён в release-конфигурацию; форма dev-записей в release скрыта.

## Подтверждённые проверки

Владелец подтвердил базовую локальную и серверную диктовку с Kari и положительно
оценил исправленный компактный overlay в dev 0.8.44. Ранее проверены копирование,
вставка, в том числе при изображении в буфере, и повторное пробуждение Лиры.
Это подтверждает проверенные пользователем сценарии, а не всю матрицу отказов,
устройств и финальных установщиков. Задержка Лиры остаётся ограничением beta.

Подтверждённый прежний [GitHub CI для v0.8.4](https://github.com/whitewolf06/Fono/actions/runs/40364351892)
не является CI-проверкой кандидата 0.9.0. Для кандидата нужны отдельные результаты
frontend/release scripts, Rust workspace, строгого Clippy, worker handshake,
упаковки Лиры, подписей installer и Docker CPU smoke. Локальные отчёты и хэши
сохраняются в `build/release-0.9.0/`; команды — в [testing](testing.md).

Установщики 0.8.0, подписанный канал обновлений и CUDA-пакет опубликованы.
Исходники новых серверных возможностей находятся в рабочей ветке. Их сборка,
включение в `main`, GitHub CI, публикация, обновление Kari и ручная приёмка
финального пакета остаются отдельными результатами.

## Открытые критерии

| Область           | Что осталось                                                                                                |
| ----------------- | ----------------------------------------------------------------------------------------------------------- |
| Лира beta         | Задержка пробуждения, независимые голоса и длительные negatives, устройства и sleep/resume                  |
| PERF-04           | Исходный строгий нулевой допуск по WER не закрыт; отдельный cardinal replay его не заменяет                 |
| Windows и GPU     | Расширенная CPU/CUDA/Vulkan-матрица, драйверы AMD/Intel, память resident/adaptive и реальные отказы worker  |
| Вставка           | Полная матрица внешних полей, повышенные права, Win+V, HTML/RTF и точные измерения задержки                 |
| Длительная работа | Аппаратный soak, 60 минут idle, hotplug и смена микрофона, ресурсы после warmup                             |
| Поставка          | Установка/обновление на чистой Windows, GUI/UAC онлайн-установщика и сохранение пользовательских данных     |
| Windows + Server  | Полная приёмка финальной сборки: перезапуск, сохранение подключения, отказы сети, повтор и локальный резерв |

Чистая Windows отложена владельцем. Автотесты, browser mock и короткий WAV replay
не заменяют её или проверку личного голоса. Детали незакрытых критериев —
в [roadmap](roadmap.md), [QA](qa/README.md) и
[архиве PERF-04](archive/improvement-plan/improvement-perf04.md).
Показатели и отрицательные опыты сохранены.

## Замороженные возможности

Старый мастер произвольной wake-фразы и `fono-wake` остаются за выключенным
legacy gate. Решение описано в [ADR 0003](adr/0003-wake-word-freeze.md);
отдельная Лира beta — в [ADR 0005](adr/0005-lira-beta.md).
Экспериментальный режим «На лету» скрыт, сохранённый `live` нормализуется в
`standard`. Свободный LLM Command Agent не реализован. Linux Desktop, macOS и
дальнейшее выделение платформенных адаптеров не входят в объём 0.9.0.
