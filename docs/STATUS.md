# Статус Fono

Обновлено 26 октября 2026 года. Версия исходников находится в
[package.json](../package.json). Последний опубликованный выпуск —
[0.8.0](releases/0.8.0.md). Этот срез заменяет
[исторический журнал](archive/status-2026-10-26.md).

## Реализовано

- Классическая диктовка с удержанием и повторным нажатием горячей клавиши,
  overlay, отменой и безопасной вставкой в исходное поле.
- Локальный Whisper на CPU/CUDA/Vulkan и офлайн GigaAM/Parakeet на CPU.
  База содержит CPU/Vulkan; CUDA-пакет устанавливается отдельно с проверкой подписи.
- Обработка и перевод через выбранное подключение, собственные инструкции,
  профили приложений и личный словарь. Незавершённая настройка обработки
  не блокирует обычную диктовку и вставку.
- История и отдельное согласие на аналитику, речевой тренер, варианты LLM
  для сохранённой записи, экспорт и локальный REST API.
- Русский и английский интерфейс. Основные настройки доступны сразу,
  второстепенные собраны в «Дополнительно».
- Восстановление WebView2 после сна и явные состояния ошибок.
- [«Привет, Лира» beta](wake-lira.md): отдельный opt-in детектор, сигнал
  готовности, повторные пробуждения и очистка фразы перед вставкой.
  Переносимый runtime входит в установщики 0.8.0; форма dev-записей в release скрыта.

## Подтверждённые проверки

Владелец подтвердил базовую диктовку, overlay, копирование и вставку, в том числе
при изображении в буфере, а также работоспособность повторного пробуждения Лиры.
Заметная задержка пробуждения сохранена как известное ограничение beta.
Эта проверка одного пользователя не закрывает матрицу голосов и оборудования.

[Fono checks на коммите 1350aba, v0.8.4](https://github.com/whitewolf06/Fono/actions/runs/40364351892)
завершился успешно во всех четырёх jobs: frontend/release scripts, Rust
core/protocol, Windows native workspace и онлайн-установщик. В native workspace
прошли 826 тестов; 9 прежних hardware/manual тестов пропущены. Строгий Clippy
и пять public feature-комбинаций прошли. Команды — в [testing](testing.md).

Установщики 0.8.0, подписанный канал обновлений и CUDA-пакет опубликованы.
Сборка, публикация, установка и ручная приёмка остаются отдельными результатами.

## Открытые критерии

| Область           | Что осталось                                                                                               |
| ----------------- | ---------------------------------------------------------------------------------------------------------- |
| Лира beta         | Задержка пробуждения, независимые голоса и длительные negatives, устройства и sleep/resume                 |
| PERF-04           | Исходный строгий нулевой допуск по WER не закрыт; отдельный cardinal replay его не заменяет                |
| Windows и GPU     | Расширенная CPU/CUDA/Vulkan-матрица, драйверы AMD/Intel, память resident/adaptive и реальные отказы worker |
| Вставка           | Полная матрица внешних полей, повышенные права, Win+V, HTML/RTF и точные измерения задержки                |
| Длительная работа | Аппаратный soak, 60 минут idle, hotplug и смена микрофона, ресурсы после warmup                            |
| Поставка          | Установка/обновление на чистой Windows, GUI/UAC онлайн-установщика и сохранение пользовательских данных    |

Чистая Windows отложена владельцем. Автотесты, browser mock и короткий WAV replay
не заменяют её или проверку личного голоса. Детали незакрытых критериев —
в [roadmap](roadmap.md), [QA](qa/README.md) и
[архиве PERF-04](archive/improvement-plan/improvement-perf04.md).
Показатели и отрицательные опыты сохранены.

## Замороженные возможности

Старый мастер произвольной wake-фразы и `fono-wake` остаются за выключенным
legacy gate. Решение описано в [ADR 0003](adr/0003-wake-word-freeze.md);
отдельная Лира beta — в [ADR 0005](adr/0005-lira-beta.md).
Экспериментальный режим «На лету» скрыт, сохранённый `live` нормализуется в
`standard`. Свободный LLM Command Agent не реализован.
