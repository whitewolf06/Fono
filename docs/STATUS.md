# Статус Fono

Дата среза: 17 октября 2026 года. Версия исходников берётся из `package.json`. Реализация в репозитории, опубликованный выпуск и установленное приложение имеют отдельные результаты. Публичные пакеты находятся в [GitHub Releases](https://github.com/whitewolf06/fono/releases); этот журнал не объявляет публикацию новой версии.

## Реализовано

- Классическая диктовка `hold`/`toggle`, общий AudioHub, речевой Silero VAD, локальный Whisper и необязательная обработка/перевод через выбранное подключение.
- Vue V3 и WhiteUI 0.6.0: основное окно, overlay, история, тренер, настройки, голосовые команды и локальный API. Browser mock использует демонстрационные данные; native runtime — настоящие порты Rust.
- GPU workers с protocol 3, readiness, ограниченным восстановлением после crash и отдельным учётом выбранного/фактического ускорения. Adaptive-резидентность освобождает модель только в простое при устойчивом давлении видеопамяти.
- Event hub и события вместо частых опросов. Скрытое окно приостанавливает чтения; новый push и поколение сессии отзывают старый ответ.
- SQLite-история, однократная миграция JSON, срок хранения вместо лимита 200, отдельный срок аналитики и очистка legacy-копий при удалении.
- Clipboard owner thread с отложенным восстановлением, ожидание отпускания физических модификаторов, привязка повторной вставки к исходным сессии и полю.
- Личный словарь, технические метаданные сессии, безопасный диагностический отчёт, loopback REST API с bearer token.
- Подписанный канал обновлений и отдельный онлайн-установщик. Автопроверка включается пользователем; загрузка и установка требуют своих действий.

Пользовательские сценарии описаны в [руководстве](user-guide.md), устройство — в [архитектуре](architecture.md). Правила выполнения работ находятся в [AGENTS.md](../AGENTS.md).

## Открытые критерии

1. **PERF-04 / FONO-79:** итоговый WER 19,5556% против прежних 18,8889%: +3 ошибки из 450, +0,6667 п.п. Допуск CI-03 +1 п.п. проходит, исходный критерий «не хуже» не выполнен. Ограничение 16→48→16 replay и DSP-аудит приведены в отчёте. Нужны независимая спецификация фильтра и настоящий широкополосный корпус.
2. **STAB-06 / FONO-112:** владелец проверяет микрофон, `hold`/`toggle`, быстрые выборы overlay, принятие без вставки, копирование, ошибки ИИ и сохранение настроек.
3. **PERF-05 / STAB-03/04:** измерение clipboard-задержки <50 мс, Win+V, восстановление HTML/RTF, удержанные модификаторы, смена поля, частичная отправка и приложения с повышенными правами. Отправка Ctrl+V не доказывает принятие текста сторонним приложением.
4. **PERF-06:** реальный crash/hang поставляемого GPU worker и восстановление выбранной модели. Процессные fixtures не заменяют проверку GPU-драйвера.
5. Реальные `resident`/`adaptive`, AMD/Intel Vulkan, CPU-only и Auto при недоступных runtime; длинные записи, sleep/resume, unplug и смена микрофона.
6. Обновление установленной версии: загрузка, подпись/версия, UAC, перезапуск и сохранение данных. NSIS/MSI на чистой Windows без SDK и исходников отложены владельцем. Онлайн-установщик требует собственного GUI/UAC-прогона.
7. Фактический запуск нового STT quality workflow в GitHub Actions и длительный lifecycle soak остаются открытыми. Локальные тесты не считаются запуском удалённого workflow.

Сценарии находятся в [QA](qa/README.md), команды автоматических проверок — в [testing](testing.md), дальнейшая работа — в [roadmap](roadmap.md). Агент не записывает микрофон, не управляет пользовательским Fono и не запускает установку ради этих проверок.

## Замороженные возможности

**WakeWord** недоступен в обычной сборке и UI. Feature выключен, прежнее включение нормализуется в `false`, фраза и профиль сохраняются. [ADR 0003](adr/0003-wake-word-freeze.md) фиксирует решение; [методики](qa/voice-reliability.md) сохраняют будущие quality gates. Возврат требует отдельного решения и проверки голоса.

**«На лету»** скрыт за выключенным feature; сохранённый `live` приводится к `standard`. План исследования не разрешает включать режим. Свободный Command Agent через LLM не реализован: доступны локальные подтверждаемые голосовые команды.
