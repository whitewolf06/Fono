# Статус Fono

Версия исходников: **0.6.13**, 2026-10-05 — очистка репозитория без нового релиза.
Последний публичный выпуск **0.6.12** доступен в
[GitHub Releases](https://github.com/whitewolf06/fono/releases/tag/v0.6.12).
CI пройден. Пользовательская приёмка установленного приложения и updater
ещё не завершена.

## Доступно в приложении

- Штатный Vue 3 + TypeScript V3 с WhiteUI 0.6.0: главная, история, речевой
  тренер, голосовые команды, API-сервис, настройки и первоначальная настройка.
  В Tauri используется native runtime; браузерный просмотр работает на mock.
- Классическая диктовка с горячей клавишей `hold` или `toggle`, речевым
  Silero VAD, отменой и единым AudioHub. Случайная запись без речи отсекается
  до STT, истории и вставки.
- Overlay с состоянием и волной, отменой/принятием, быстрым выбором обработки,
  стиля и перевода во время записи в режиме повторного нажатия.
  Завершение клавишей вставляет текст; принятие в overlay оставляет результат
  для копирования без вставки.
- Auto/CPU/CUDA/Vulkan, отдельные GPU workers с protocol 3, readiness,
  подготовкой модели, health и отменой. Подготовка release проверяет
  handshake каждого поставляемого worker.
- Политики памяти `resident` и `adaptive`. Первая сохраняет быстрый старт;
  вторая освобождает GPU-модель при устойчивой нехватке памяти только в
  простое и загружает её по запросу. Сейчас мониторинг ограничен одной
  аппаратной GPU с поддерживаемой выделенной памятью Windows.
- OpenAI-совместимые профили и модели обработки: очистка, структурирование,
  постановка задачи, деловой стиль, исходный текст и отдельный перевод.
  Для четырёх редакторских стилей есть стандартные/свои промпты и тест текстом
  или пробной диктовкой. `raw` без перевода не вызывает LLM.
- Последний результат сессии независимо от архива; исходный и обработанный
  варианты, ручная правка, повторное улучшение, отмена улучшения и копирование.
- Локальная история с датой, временем, длительностями, моделью и фактическим
  backend. Речевой тренер показывает периоды, речевые привычки, разборы и
  сортировку диктовок. Личный словарь опционален и выключен по умолчанию.
- Локальные команды с allowlist и подтверждением. Обычная диктовка не
  интерпретируется как команда.
- Loopback API с bearer authentication, отдельной очередью, отменой,
  результатами и документацией. Подробнее: [LOCAL_TRANSCRIPTION_API.md](LOCAL_TRANSCRIPTION_API.md).
- Настройки/история с атомарным сохранением и миграциями; API-ключи в Windows
  Credential Manager; локальный диагностический отчёт без пользовательских
  текстов и секретов; автозапуск Windows.
- Подписанный канал GitHub Releases и ручная проверка обновления.
  Необязательные фоновые проверки — при запуске и раз в сутки с общим
  ограничением 24 часа. Автоматической загрузки/установки нет; явная установка
  ждёт завершения активных операций.

## Временно недоступно

- **WakeWord:** скрыт/заблокирован до доработки качества. Native gate запрещает
  активацию и тесты, сохранённое включение приводится к выключенному. Код,
  модели и предпочтения сохраняются для дальнейшей работы.
- **Поэтапный вывод «На лету»:** скрыт после ручной проверки; `live`
  нормализуется в `standard`. `hold` и `toggle` оба используют классический
  результат после завершения записи.
- **Command Agent через LLM:** свободная интерпретация команд не реализована;
  действуют локальные правила и подтверждаемые действия.

## Что подтверждено автоматически

Для 0.6.12 пройдены проверки фронтенда, версий, форматирования, release
scripts и native CI: workspace tests, strict Clippy, format и feature matrix.
Windows-тесты получают точные четыре Sherpa/ONNX DLL рядом с исполняемыми
файлами через `scripts/test-native.ps1`; системный ONNX runtime не подменяет
закреплённую версию. Подписанные assets опубликованы в публичном канале.

Ранее короткие публичные WAV проверялись с CUDA/Vulkan на RTX 5070 Ti;
подтверждён desktop-dev API smoke с загрузкой WAV, polling, отменой и
закрытием loopback-порта после выхода. Эти результаты не подтверждают
микрофон, установленную версию или работу адаптивной памяти на другой GPU.

## Приёмка остаётся

1. Пользовательский прогон `hold`/`toggle`, быстрых выборов overlay,
   принятия без вставки, копирования, ошибок ИИ и сохранения настроек.
2. Реальное обновление из установленной версии: проверка → загрузка →
   подпись → установка/UAC → перезапуск с прежними настройками и историей.
3. `resident`/`adaptive` под реальной нагрузкой GPU: освобождение только
   в простое, загрузка по запросу, отсутствие постоянных перезагрузок.
4. Отложенная пользователем проверка NSIS/MSI на чистой Windows без
   окружения разработчика, включая первый запуск и обновление.
5. AMD/Intel Vulkan, CPU-only и Auto при недоступных GPU runtime/драйверах.
6. Длительные записи, sleep/resume, смена/отключение микрофона, восстановление
   после сбоев и реальные поля Windows/clipboard.

Приёмку голоса и окон выполняет пользователь. Unit tests, browser mock,
успешная сборка и публикация не заменяют эту проверку.
