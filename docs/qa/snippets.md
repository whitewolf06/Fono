# Ручная проверка сниппетов

В настоящем Fono с Rust, без необходимости устанавливать installer.

1. Открыть **Настройки → Аудио и распознавание → Сниппеты**. Добавить
   «моя подпись» → «С уважением, Дмитрий», сохранить, включить общий выключатель.
   Проверить сохранение после перезапуска. Отключить запись и весь механизм:
   шаблон сохраняется, новые диктовки его не используют.
2. В своём тестовом поле произнести точную фразу. Должен появиться шаблон,
   без LLM даже с включённой обработкой/переводом и недоступным LLM endpoint.
   «Это моя подпись», «Какая моя подпись?» и фраза с продолжением должны
   распознаваться обычным способом, без substring-срабатывания.
3. Проверить `{date}`, `{time}`, два вхождения `{clipboard}` и кириллицу.
   В буфер заранее поместить тестовый текст с буквальным `{date}` — он
   не должен раскрываться второй раз. Без `{clipboard}` приложение не должно
   читать буфер для подстановки. Изображение/locked clipboard/большой текст должны дать
   понятный отказ, без отправки исходного триггера в LLM.
4. Во время распознавания/подготовки сниппета сменить внешнее поле или отменить
   сессию. В новое поле текст не отправляется, поздний результат не появляется.
   Проверить Copy/Cancel после ошибки и отсутствие повторной частичной вставки.
5. Проверить hold/toggle, ручной режим и overlay Accept: последний сохраняет
   результат для копирования без внешней вставки; Copy не раскрывает шаблон
   заново и не меняет дату/clipboard уже подготовленного результата.
6. Экспортировать JSON, изменить шаблон и импортировать файл обратно.
   Проверить подтверждение замены непустого списка и отдельное сохранение.
   Cancel picker/подтверждения не должен менять список. Импорт не включает
   общий выключатель. Экспорт сохраняет `{clipboard}` буквально.
7. Импортировать повреждённый JSON, неизвестную версию/поле, дубликаты триггеров,
   превышение лимитов. Старый список должен сохраниться. Строка со скриптом или
   командой остаётся текстом — её нельзя выполнять как часть импорта.
8. Проверить, что обычные голосовые команды, файл и REST-задание не подменяют
   расшифровку сниппетом. Диагностический отчёт не должен содержать шаблоны,
   trigger или тестовый clipboard.

Записать версию, модель, источник диктовки, выбранный способ вставки и результат.
Личные шаблоны и содержимое буфера прикладывать не нужно.
