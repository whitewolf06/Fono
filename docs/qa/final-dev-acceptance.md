# Общая приёмка dev Fono

Срез: 22 октября 2026 года, v0.7.66. Основной план — FONO-47;
ручная редактура истории FONO-27 и контекст приложений FONO-28 включены сюда,
чтобы проверить оставшееся за один проход. Это список для настоящего Windows
dev с Rust, а не для браузерной демонстрации.

Базовые hold/toggle, автовставка при изображении в буфере, Copy из overlay,
отмена, смена поля и одна запись истории уже подтверждены владельцем.
Повторять весь этот блок сейчас не нужно. Если в новых сценариях встретится
регрессия, укажи шаг и наблюдаемое поведение.

По отдельной просьбе владельца текущий шаг —
[записать образцы WakeWord в Fono](../improvement-wake-samples.md#первый-набор-от-владельца).
Это подготовка данных для детектора; автоматическое пробуждение пока выключено.
Остальные пункты ниже сохраняются для последующего общего прохода.

## Один проход по оставшимся возможностям

Используй специально созданные пробные записи и поля. Отмечай строки по мере
проверки; личные тексты, ключи и аудио прикладывать не нужно. Возможность,
которую сейчас не используешь, можно отметить «отложено», без повторных кругов.

| Проверка                                             | Что сделать и какой результат ожидать                                                                                                                                                                                                                                                                                                                              |
| ---------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| [ ] **Подключение и обработка** — FONO-27/141        | В «Обработка текста и ИИ» выбери свой локальный сервер Ollama/LM Studio и модель, сохрани. Проверь список моделей, один стиль и перевод. При недоступном уже настроенном сервере исходный текст остаётся доступным. Для облака нужен обычный профиль с доступом к Windows credentials; изолированный dev ключи не сохраняет. [Подробности](local-llm-presets.md).  |
| [ ] **Правка истории** — FONO-27                     | Открой пробную архивную запись, обработай её, сравни оригинал и вариант. Проверь другой стиль, копирование и удаление только варианта. Оригинал сохраняется. При переключении записи поздний ответ не должен появиться у новой. Облачная отправка требует отдельного согласия. [Подробности](history-rewrite.md).                                                  |
| [ ] **Голосовая правка выделения** — FONO-128…131    | В своём тестовом документе выдели текст и запусти настроенную команду правки. Сначала проверь результат без автоматической замены, затем явное применение. Смена поля/выделения не разрешает отправить ответ в другую цель. Для других приложений повтори только там, где планируешь пользоваться.                                                                 |
| [ ] **Профили, язык и overlay** — FONO-133/136       | Создай правило для редактора кода: язык, стиль и способ вставки. Начни диктовку в нём и измени быстрый выбор в overlay. Применяется последний сохранённый выбор; правило следующей диктовки определяется её исходным приложением. Кнопки overlay сохраняют фокус поля. [Профили](application-profiles.md), [язык](overlay-recognition-language.md).                |
| [ ] **Контекст и приватность** — FONO-28             | Включи «Сохранять приложение для вставки», надиктуй в два приложения. В истории есть имя exe без пути, фильтр и сводка попыток; «Попытка вставки» не обещает подтверждённый приём полем. Выключи сбор, затем удали только контекст пробной записи: текст и варианты LLM остаются. [Подробности](application-context.md).                                           |
| [ ] **Словарь и сниппеты** — FONO-132/135            | Добавь пробный термин и точную фразу для сниппета. Термин применяется после обычной диктовки; точный триггер возвращает шаблон без LLM. Фраза с продолжением не должна запускать сниппет. Для `{clipboard}` используй свой тестовый текст. Проверь выключение без потери записей. [Сниппеты](snippets.md).                                                         |
| [ ] **Файлы и очередь** — FONO-134                   | Добавь короткий WAV/MP3 через диалог и перетаскивание при выключенном API. Экспортируй TXT и, если модель даёт метки, SRT/VTT. Во время длинного файла запусти обычную диктовку: она получает приоритет, файл затем продолжается. Отмени файл и добавь новый. [Подробности](file-transcription.md).                                                                |
| [ ] **Триггеры и автостоп** — FONO-125…127/138       | Проверь нужный дополнительный триггер; прежний hotkey остаётся рабочим. Включи автостоп toggle, произнеси фразу и выдержи заданную паузу. Речь сбрасывает ожидание, отмена не завершает следующую запись. Тишина не создаёт текст и историю. [Подробности](toggle-auto-stop.md).                                                                                   |
| [ ] **Предварительное распознавание** — FONO-120…124 | Только если хочешь проверить эксперимент: включи настройку, продиктуй около минуты с паузами, затем останови и отдельно отмени новую запись. До Stop внешней вставки нет, итог один, после отмены нет позднего текста. Сравни субъективное ожидание с выключенной настройкой на той же модели. По умолчанию она выключена; этот опыт не заменяет WER/latency gate. |
| [ ] **Тренер, звуки и язык UI** — FONO-137/139/140   | При отдельном согласии на аналитику проверь темп/паузы новой записи и период в тренере. Включи сигналы и послушай начало/конец: тихое начало речи не теряется. Переключи RU/EN — основные экраны, tray и overlay согласованы, язык распознавания сам не меняется. [Тренер](trainer-speech-timing.md), [звуки](recording-sounds.md), [UI](interface-language.md).   |
| [ ] **Модели и восстановление** — FONO-113…119/81    | На реально нужных моделях/ускорениях проверь загрузку, одну диктовку и смену модели. Сохрани название модели и фактический backend из истории. После сна и переподключения микрофона приложение либо работает, либо показывает ошибку с возможностью повторить. Не завершай GPU worker принудительно в обычном рабочем сеансе.                                     |
| [ ] **Полный перезапуск** — FONO-112/27/28           | Выйди из dev целиком через tray и запусти его с тем же профилем. Проверь настройки, словарь, сниппеты, профили, варианты истории и удалённый контекст. Закрытие и повторное открытие окна не заменяют эту проверку. [Контекст](application-context.md), [история](history-rewrite.md).                                                                             |

Для результата достаточно: «строки 1–4 прошли; 5 — после очистки осталась
метка; 6–8 отложено». Для ошибки укажи версию, модель/backend, шаг и ожидаемое
поведение. Успешные строки повторно не запускаем без изменения связанного кода.

Дополнение v0.7.65: при ограничении подсказки словаря Fono отдаёт приоритет
частым, затем недавно использованным терминам текущего процесса. Счётчики
только в памяти; после перезапуска или выключения словаря действует порядок
редактора. Общая проверка словаря остаётся в той же строке, нового отдельного
круга ручных сценариев не требуется.

## Хвосты, которые этот проход не закрывает

| Задача                | Остаток                                                                                                                                                                                            |
| --------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **PERF-04 / FONO-79** | Строгий quality gate ресемплера остаётся открытым. Принятые критерии и база сравнения не изменены; новые эксперименты в этом проходе не запускались.                                               |
| **FONO-118/119**      | Полное CPU-сравнение Whisper/квантованных вариантов и CUDA-квалификация. Незавершённая серия не превращается в итоговую метрику.                                                                   |
| **FONO-124**          | Vulkan/EN timeout, точный замер Stop, полный расход worker RAM/VRAM и конкуренция API. Предварительное распознавание остаётся opt-in.                                                              |
| **FONO-132**          | Рост общей WER при полезных терминах; hotwords GigaAM/Parakeet не квалифицированы. Приоритет частых/недавних терминов реализован в v0.7.65; финальные замены и отдельное согласие на LLM доступны. |
| **FONO-143…146**      | Для WakeWord нет согласованного достаточного корпуса и принятого качества; обучение/интеграция/персонализация остаются за своими условиями. WakeWord и старый live выключены.                      |
| **FONO-75/112**       | Подпись и публикация CUDA-пакета, установленный updater/онлайн-установщик, UAC и отложенная чистая Windows. Текущий dev не подтверждает поставку.                                                  |
| **FONO-107…109/112**  | Удалённые GitHub Actions и аппаратный soak, длительный idle, GPU/устройства. Автоматические локальные тесты и короткий пользовательский проход их не заменяют.                                     |

FONO-24 с контрольной темой относится к отдельному эпику FONO-19 и не включена
в этот проход FONO-47. Полные методики остаются в [разделе QA](README.md).
