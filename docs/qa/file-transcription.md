# Ручная проверка файлов Fono

Desktop dev или собранный Tauri с Rust. Browser preview проверяет только экран
и деморезультаты. Приёмка installer и чистой Windows проводится отдельно.

1. Выключить API-сервис. Открыть **Файлы**, добавить несколько WAV/MP3/FLAC/OGG
   через диалог и drag&drop. Проверить имена с пробелами и кириллицей, порядок
   очереди, подготовку и прогресс. API должен остаться выключенным. Исходные
   файлы должны остаться на месте.
2. Добавить больше четырёх ожидающих файлов: должны быть видны принятые задания
   и сообщение о не добавленных. Повторить с недоступным, повреждённым,
   неподдерживаемым и слишком большим файлом. Отмена диалога ничего не добавляет.
3. Выбрать Whisper и реальную запись длительностью 30 минут. После окончания
   сохранить TXT, SRT и VTT. Открыть субтитры в проигрывателе, проверить начало,
   границы окон примерно 18/36/54 секунд, паузы, середину и конец по аудио.
   Не должно быть систематического сдвига, повторов overlap или потери конца.
4. Во время файла запустить обычную диктовку горячей клавишей. Диктовка должна
   получить STT, файл — затем продолжиться с текущего checkpoint. Повторить
   несколько раз; записать модель, backend и наблюдаемую задержку.
5. Отменить pending, подготовку и активный STT; затем добавить новый файл.
   Поздний результат отменённой операции не появляется, следующий файл работает.
   Проверить «Отменить все» и выход во время подготовки/STT: worker завершается,
   установка обновления не начинается до завершения actual work.
6. Включить API и поставить REST-задание одновременно с файлом. Убедиться,
   что они используют общую очередь, диктовка сохраняет приоритет. После
   завершения выключить API и повторно добавить файл через экран.
7. Проверить кнопку сохранения: отмена не создаёт файл, существующий файл
   требует согласия на перезапись, ошибка доступа оставляет результат доступным.
   После перезапуска результат можно открыть и экспортировать из истории экрана.
8. Проверить старую запись без меток: TXT доступен, SRT/VTT выключены.
   Для GigaAM/Parakeet проверить фактическую поддержку меток выбранной моделью;
   отсутствие меток должно давать TXT-only, без выдуманных интервалов.

Зафиксировать версию Fono, модель, фактический backend, длительность файла,
действия и результат. Аудио и личную расшифровку прикладывать не требуется.
