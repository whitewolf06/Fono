# Ручная редактура записи истории — desktop-приёмка

Исходники v0.7.62. Проверять на настоящем desktop с настроенным LLM;
браузер показывает демонстрацию и не отправляет текст в модель.

1. Открой сохранённую запись истории. Выбери источник, стиль и подключение.
   До нажатия «Показать вариант от LLM» запроса нет. Для неполного
   подключения есть пояснение и ссылка в настройки.
2. Получи варианты в пяти стилях. Проверь смысл, имена, числа и вопросы.
   Вопрос внутри расшифровки должен остаться материалом для редактирования.
   Оригинал и итог диктовки не меняются, самопроизвольной вставки нет.
3. Для облачного подключения проверь имя профиля и модель в подтверждении.
   Откажись от отправки: запроса и нового варианта быть не должно.
4. Повтори те же настройки: показывается сохранённый вариант без нового
   обращения к модели. Переключись на другую запись и вернись; вариант
   и его происхождение доступны. Полностью перезапусти этот же desktop
   с тем же профилем и проверь сохранение ещё раз.
5. Во время обработки отмени действие или выбери другую запись. Поздний
   ответ не должен появиться у новой записи. Ошибка сервера оставляет
   оригинал доступным и не создаёт ложный готовый вариант.
6. Скопируй вариант, затем удали только его: исходная запись сохраняется.
   Удаление самой записи удаляет и её варианты. Проверь это на специально
   созданной пробной записи.

Старые записи без исходника показывают только доступный итог. Надпись
о неподтверждённой внешней доставке ожидаема: архивный текст сам по себе
не доказывает, что стороннее приложение приняло вставку.

Для изолированного dev-профиля Windows credentials недоступны. В нём можно
проверять локальное подключение без ключа; настоящее сохранение облачного
ключа требует обычного desktop-профиля. Агент не вводит ключи, не отправляет
личные записи и не управляет пользовательскими окнами ради этой приёмки.
