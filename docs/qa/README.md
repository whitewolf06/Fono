# Приёмка и воспроизводимые проверки

Этот раздел хранит сценарии, по которым владелец проверяет настоящий Windows runtime. Команды автоматических тестов находятся в [testing](../testing.md), выполненные прогоны и открытые критерии — в [STATUS](../STATUS.md).

| Методика                                  | Сценарии                                                                    |
| ----------------------------------------- | --------------------------------------------------------------------------- |
| [Диктовка](dictation-controls.md)         | Hold/toggle, отмена, принятие результата, история и внешнее поле            |
| [Индикатор и промпты](overlay-prompts.md) | Фокус, быстрый выбор, сохранение настроек и тест инструкции                 |
| [Память и обновления](memory-updates.md)  | Residency, расписание обновлений и ручной update flow                       |
| [Голосовое ядро](voice-reliability.md)    | Общие контракты, WAV replay и отдельные методики замороженных экспериментов |

Browser mock проверяет интерфейс и демонстрационные порты. Rust/process fixtures проверяют свой native-контракт. Голос, глобальная клавиша, сторонние поля, GPU-драйверы, UAC и установленное приложение требуют своего прогона. Отсутствие такой проверки сохраняется в STATUS, а не повторяется в каждом пользовательском разделе.

Агент не записывает микрофон и не управляет пользовательским приложением ради приёмки. WakeWord и режим «На лету» остаются выключенными. Методика для будущего эксперимента не разрешает включать его.
