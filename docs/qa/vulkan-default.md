# Проверка основной поставки Vulkan

Дата: 13 ноября 2026 года. Версия кандидата: 0.9.1. Решение о поставке —
[ADR 0006](../adr/0006-vulkan-default-optional-cuda.md).

## Что изменилось

Auto в общем STT-ядре выбирает Vulkan на подходящей физической дискретной GPU.
Без неё используется CPU. Программный Vulkan и встроенная графика не включают
GPU в Auto. Установка дополнительного CUDA-пакета не меняет Auto; CUDA
выбирается явно. Ошибка загрузки модели или нехватка памяти на выбранной GPU
возвращается пользователю.

Базовые ресурсы Windows содержат только Vulkan worker; CPU остаётся встроенным.
Подписанный CUDA-пакет и его проверка сохраняются. Для API подготовлены отдельные
Dockerfile и CI-задания Vulkan/CUDA. Основные теги образа назначаются только
Vulkan-варианту. Кэш шейдеров сохраняется отдельно от моделей.

## Подтверждённые проверки

- Windows: 371 тест общего ядра, типов, сервиса и сервера; 4 пропущены.
- Windows Desktop: 710 тестов пройдено; 6 пропущены.
- V3: 491 тест пройден. Проверки типов, линтер и сборка прошли.
- Release-контракты: 54 теста пройдено. Producer CUDA-пакета: 13 тестов,
  один платформенный сценарий пропущен.
- Linux в сборке основного образа: 357 тестов пройдено, 4 пропущены;
  строгий Clippy сервера и общих crates прошёл.
- Обновлённый Windows Vulkan worker собран. Процессный контракт проверяет
  protocol 4, инвентаризацию физических устройств и наличие прогрева обоих
  графов. Этот прогон не загружает модель и не измеряет распознавание.
- Docker-контекст проверен фактическим экспортом: около 26,9 МБ. Модели,
  CUDA DLL, пользовательские данные и локальные кэши в него не попадают.
- На Kari изолированно проверены Auto с GPU, Auto без GPU и явный Vulkan
  без GPU: соответственно Vulkan, CPU и отказ запуска/doctor.

## Распознавание и прогрев на Kari

Устройство: RTX 3060 Ti 8 ГБ, драйвер 595.99.02. Модель — FP16 Large v3 Turbo,
SHA-256 `1fc70f774d38eb169993ac391eea357ef47c88757ef72ee5943879b7e8e2bc69`.
Корпус — 20 публичных записей FLEURS, 10 RU и 10 EN; три измеряемых повтора,
60 HTTP-запросов. Квота контейнера — 8 CPU и 6 ГиБ RAM.

Внутренний прогрев выполняется до `model_loaded` для классического и оконного
распознавания. В проверке с новым worker подготовка с пустым кэшем занимала
11,48 с; первый пользовательский запрос — 344,83 мс. Медиана последующих
запросов — 353,43 мс, p95 по ближайшему рангу — 481,03 мс. Одного классического
прогрева оказалось недостаточно: первый запрос API занимал 2,57 с.

Нормализованные расшифровки нового Vulkan worker совпали с предварительным
CUDA-прогоном на 20 из 20 записей. WER: RU — 19/205, EN — 9/245. Это небольшой
проверочный корпус; он не подтверждает равенство качества на произвольном аудио.
В сравнительном CUDA-прогоне медиана была 345,74 мс, p95 — 450,90 мс.

Этот замер выполнен с целым собранным API-образом, без подмены worker.
Исходные результаты: `build/vulkan-default-0.9.1/results/api-vulkan-final.json`
и `results/summary-final.json`; CUDA-основание —
`build/vulkan-eval-0.9.0/results/api-cuda.json`.
Процентили пересчитаны из сырых измерений общим проверенным scorer;
в исходном коллекторе индекс p95 был смещён на одну позицию.

Бюджет `VK_EXT_memory_budget` относится к процессу. Он не выдаётся за глобальную
свободную VRAM: неизвестное значение остаётся неизвестным. Фактическое участие
GPU проверяется драйвером с сопоставлением PID worker из тестового контейнера.

## Открытая приёмка

Windows GPU-замеры отложены владельцем до закрытия игры. При последней проверке
игра работала, загрузка GPU составляла 99%; распознавание для замеров не запускали.
AMD и Intel аппаратно не проверены. Микрофон, горячие клавиши, поля и оверлей
проверяет владелец; автоматического управления приложением не было.

Архив собранного Vulkan API без моделей занимает 161 233 641 байт,
или 153,76 МиБ. Это gzip-архив Docker image; размер установленного образа и
отдельно загружаемых моделей учитывается отдельно. Готовый образ прошёл CPU/GPU
smoke и принудительное завершение своего worker: текущий запрос вернул
`502 worker_failed`, следующий восстановил Vulkan и вернул 200. Драйвер подтвердил
1821 МиБ VRAM у PID этого worker; это снимок потребления, не измеренный пик.
Краткие результаты и хеш архива — [проверочный отчёт](../evidence/vulkan-default-0.9.1.json).
Рабочий Kari остаётся на `0.8.42-cuda`. Публикация, установка и обновление рабочего
сервера не выполнялись.
