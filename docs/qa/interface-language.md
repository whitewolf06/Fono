# Приёмка языка интерфейса

Сценарий FONO-137 для Windows runtime. Browser mock и автоматические проверки
описаны в [отчёте](../improvement-fono137.md). Владелец выполняет действия
самостоятельно; агент не записывает микрофон и не управляет его приложением.

1. На русской Windows открыть Fono со старыми настройками без `ui_language`.
   Ожидается русский интерфейс и «Как в системе». На другой системной локали
   ожидается English. Проверять язык интерфейса Windows, а не раскладку клавиатуры.
2. Открыть «Настройки → Основные → Язык интерфейса». Выбрать English, нажать
   «Отмена»: язык остаётся прежним. Выбрать снова и сохранить: меняются навигация,
   подписи, календарь WhiteUI, сообщения и меню tray. Повторить обратно на RU.
   Перезапустить Fono: ручной выбор сохраняется. Вернуть «Как в системе».
3. Для RU и EN пройти главную, файлы, историю, команды, тренер, API, обновления,
   первоначальную настройку и все разделы настроек при 720×560, 900×720 и
   1440×900. Открыть используемые диалоги и выпадающие списки. Текст читается,
   кнопки доступны, горизонтальное прокручивание страницы не требуется.
4. Проверить tray и подробный/компактный overlay: язык соответствует выбранному,
   статусы записи и обработки переведены. Кнопки overlay не активируют окно и
   не отбирают фокус. Настройка языка распознавания RU/EN/Авто остаётся отдельной.
5. Сохранить русский текст, собственную инструкцию, имя профиля и сниппет
   с `{date}`, `{time}`, `{clipboard}`. Переключить интерфейс: содержимое,
   голосовые фразы, язык распознавания и язык перевода не меняются. Числа,
   плотности и подсветка аналитики дают те же результаты.
6. В English посмотреть встроенные инструкции обработки и выполнить обычный
   сценарий с выбранным подключением. Без перевода исходный язык сохраняется;
   явный перевод использует заданный язык. Собственная инструкция остаётся
   в исходном виде. `raw` без перевода работает без подключения к LLM.

Для безопасной проверки ошибки можно использовать недоступное локальное
подключение. Сообщение должно быть на выбранном языке, без сырых адресов,
секретов и stderr. Старую составную ошибку допускается повторно получить после
смены языка: уже показанный текст может сохранять язык первоначального ответа.

Результат приёмки фиксируется отдельно: версия исходников, язык Windows,
ручной выбор, размеры окна, фактическое поведение и оставшиеся замечания.
Проверки языка не требуют устанавливать обновление или CUDA-пакет.
