# Локальные LLM — ручная приёмка

Проверять desktop runtime с исходниками v0.7.57 или новее.
Browser mock проверяет форму, но не обращается к Ollama или LM Studio.

1. Запустите нужный сервер с OpenAI-compatible API. В Fono откройте
   «Настройки → Обработка текста и ИИ → Профили подключений → Добавить».
   Выберите Ollama или LM Studio. Проверьте адрес и пустой ID модели.
   До отдельной проверки список не загружается, генерация не запускается.
2. Нажмите «Проверить сервер и найти модели». Выберите настоящий ID,
   сохраните профиль, затем выберите его для обработки и сохраните раздел.
   Перезапустите desktop Fono: профиль, ID и выбор должны сохраниться.
3. Остановите локальный сервер и повторите проверку. Ожидается понятная
   ошибка; сохранённый профиль и другие настройки остаются на месте.
   После запуска сервера повтор должен работать. Пустой список должен
   предлагать подготовить модель или ввести ID вручную.
4. Для сервера с обязательным ключом анонимная проверка шаблона может
   отказать. Введите ключ и ID в профиль, сохраните его и используйте
   обычную «Проверить соединение» в разделе обработки. Ключ в форме
   скрыт; не прикладывайте его к отчётам или скриншотам.
5. Начните поиск и сразу смените шаблон или закройте форму. Старый список
   не должен появиться в следующем черновике. Проверьте ручной ввод ID
   после успешного поиска; сохранение не должно запускать генерацию.
6. Отдельно и по своей кнопке проверьте обработку короткого тестового
   русского текста. Сравните сохранение смысла и отсутствие добавленных
   фактов. Успех `GET /models` этого не доказывает.

Измеренный рейтинг моделей остаётся отдельным хвостом FONO-141/FONO-69.
Для него нужны фиксированные корпус и промпт, точные модель/квантизация,
версии сервера и оборудования, оценки смысла/выдумок и время до результата.
Один успешный ответ или размер модели не заменяют такую проверку.
