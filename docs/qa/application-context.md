# Контекст приложения — ручная Windows-приёмка

Исходники v0.7.63. Проверка владельцем на настоящем desktop;
браузер использует вымышленные приложения и не проверяет внешнюю вставку.

1. В «История и приватность» убедись, что «Сохранять приложение для вставки»
   выключено по умолчанию. Диктовка работает как прежде, новых метаданных нет.
2. Включи настройку и историю. Надиктуй пробный текст в Блокнот и редактор кода.
   В истории должны появиться имя exe без пути и «Попытка вставки».
   Приём текста полем не объявляется подтверждённым. Проверь Clipboard и SendInput.
3. Во время диктовки смени поле/окно. При остановке безопасная блокировка остаётся;
   в архиве принятого для копирования результата ожидается «Сменился фокус»
   или неизвестное приложение, без ложного назначения новому окну.
4. В истории выбери приложение и период. Фильтр меняет список; сводка считает
   попытки за период независимо от фильтра/поиска. Закрытая без вставки диктовка
   не увеличивает число попыток. Проверь подпись браузера как целого приложения.
5. Выключи сбор. Метки скрываются, новые диктовки контекст не получают.
   После повторного включения старые сохранённые метаданные снова доступны;
   ожидавшая во время переключения операция не должна вернуть старый снимок.
6. На специально созданных записях удали контекст одной записи, затем всех.
   Текст, исходная расшифровка и варианты LLM должны остаться. Проверь полный
   перезапуск процесса с тем же профилем; удалённые метаданные не возвращаются.

Смена поля и частичная отправка не разрешают автоматический повтор.
Старые записи показывают «Не собиралось». Если Windows не разрешает определить
exe или использует host-процесс, Fono не подставляет название документа/вкладки.
Субъективную задержку сравнивай на тех же приложении, модели и диктовке;
автоматический тест не подтверждает ощущение скорости на рабочем компьютере.
