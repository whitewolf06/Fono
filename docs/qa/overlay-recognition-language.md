# Язык распознавания в индикаторе

Ручная проверка настоящего Fono с Rust на Windows. Installer не требуется.

1. Выбрать установленную многоязычную модель Whisper, режим повторного нажатия
   и включить быстрые настройки индикатора. Начать запись в своём тестовом поле.
   Кнопка RU / EN / Авто открывает выбор **языка распознавания**; язык перевода
   настраивается отдельно. Проверить подробный и компактный вид.
2. Выбрать EN во время записи, закончить сочетанием клавиш. Проверить распознавание
   английской речи, следующую диктовку и сохранение выбора после перезапуска.
   Повторить с RU и Авто. Сразу после выбора нажать Stop: распознавание должно
   дождаться сохранения. После Stop выбор заблокирован.
3. Проверить принятие кнопкой overlay: внешний фокус сохраняется, текст готовится
   без внешней вставки и остаётся для Copy/Close. Отмена и поздний ответ от старой
   сессии не меняют следующую запись. Частичная вставка не повторяется.
4. При ошибке сохранения должен вернуться последний подтверждённый язык;
   завершение блокируется до успешного повтора или отмены. Исходная запись
   остаётся доступной. Ошибка не должна сохранять неподтверждённый язык.
5. Для GigaAM показывается «Только RU», для Parakeet — «Язык: авто».
   Ручной выбор EN/RU не предлагается. Для произвольной модели с неизвестной
   capability переключатель скрыт. Смена модели в основных настройках во время
   записи не меняет capability уже начатой сессии.
6. Если включено предварительное распознавание длинной записи, после получения
   первого фрагмента сменить язык. Stop должен заново распознать полный PCM
   с выбранным языком, без склейки старого префикса с новым хвостом. Это допустимо
   дольше обычного Stop. Реальное качество проверить на RU/EN, включая короткие слова.
7. Для профиля приложения проверить исходный язык из session snapshot, ручной
   выбор поверх него и сохранность самого профиля. Следующий старт снова учитывает
   профиль приложения; глобальные настройки остаются базой для остальных приложений.

Browser mock и unit tests проверяют интерфейс и контракты. Они не подтверждают
качество настоящей речи, работу Windows hotkey, внешний фокус или вставку.
