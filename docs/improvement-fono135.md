# FONO-135 — локальные сниппеты

Исходники v0.7.50, 21 октября 2026 года. Реализован F-08.1 из истории FONO-63.
База — v0.7.49 / `7819f55`. В актуальном `tasks.get_context` у FONO-135 нет
блокирующих dependency links. Использованы существующие snapshot настроек,
обычная диктовка, pending workflow, clipboard owner и защищённая вставка.
FONO-135 передаётся в `in_review`, история FONO-63 — в `in_progress`;
ручная голосовая Windows-приёмка остаётся открытой.

## Поведение

- В **Настройки → Аудио и распознавание → Сниппеты**, рядом со словарём,
  доступны создание, изменение, удаление, отключение отдельных записей и общий
  выключатель. Он выключен по умолчанию; выключение сохраняет шаблоны.
  Записи сохраняются кнопкой «Сохранить», общий выключатель применяется сразу.
- Триггер совпадает только со всей исходной расшифровкой. Нормализация:
  регистр, `ё/е`, пробелы, точка/восклицательный знак/многоточие в конце.
  Вопросительный знак сохраняется; триггер-вопрос не принимается. Подстрока
  в вопросе или длинной фразе не срабатывает. Дубликаты нормализованных
  триггеров отклоняются, включая отключённые записи.
- Сниппет выбирается из snapshot конкретной диктовки до LLM. Его текст
  проходит без LLM, перевода и замен личного словаря, даже если обычная
  обработка включена. Исходная расшифровка сохраняется отдельно от результата.
  Метаданные истории отмечают фактически пропущенные LLM/перевод/словарь.
- `{date}` — местная дата `ДД.ММ.ГГГГ`, `{time}` — `ЧЧ:ММ`, `{clipboard}` —
  текущий текстовый буфер. Подстановка однопроходная: переменные внутри
  clipboard повторно не раскрываются. Неизвестные фигурные скобки — обычный
  текст; скрипты, команды, пути и выражения не вычисляются.
- Clipboard читается один раз только при совпадении включённого сниппета
  с явной переменной `{clipboard}`. Используется существующий Win32 owner;
  чтение не вызывает Ctrl+C, не читает чужие поля и не изменяет буфер.
  При незавершённом восстановлении, недоступном/нетекстовом/слишком большом
  буфере выводится ошибка; исходный текст остаётся в pending для явного решения.
- Развёрнутый текст идёт через прежний captured target и one-shot insertion.
  Смена поля и частичная вставка запрещают автоматический повтор. Overlay Accept
  сохраняет copy-only workflow; clipboard не перечитывается при обычном Copy.
  Отмена/замена операции запрещает позднюю публикацию и вставку. Lease подготовки
  принадлежит фактическому blocking worker и clipboard owner, включая отмену
  ожидающего IPC/future.
- Голосовые команды, REST/файловые задания, diagnostic/processing tests и скрытый
  live не используют сниппеты. WakeWord/live не включались.

## JSON и ограничения

Формат файла:

```json
{
  "version": 1,
  "snippets": [
    {
      "trigger": "моя подпись",
      "text": "С уважением, Дмитрий\n{date}",
      "enabled": true
    }
  ]
}
```

До 64 записей, триггер до 80 символов, шаблон до 8192, общий размер до
128 × 1024 символов, JSON до 1 МиБ, готовый результат до 32 × 1024 символов.
Неподдерживаемая версия, неизвестные поля, неверные типы, управляющие символы,
пустые/дублирующиеся триггеры и превышение лимитов отклоняются до сохранения.
Поле `enabled` при его отсутствии в JSON означает `true`; сам импорт не
включает общий выключатель.

Native import/export используют Windows file dialog на owning UI thread
и файловый I/O в blocking worker. Импорт возвращает проверенный черновик;
замена непустого списка в форме требует отдельного решения, затем обычного
сохранения настроек. Экспорт включает текущие шаблоны формы, без значений
clipboard и без раскрытия даты/времени. Cancel не сохраняет изменения.

Browser mock использует типизированный порт импорта/экспорта и ту же схему.
Записи и выключатель остаются в памяти: содержимое не попадает в browser storage.
Vue-компоненты не обращаются к файловым/browser API или IPC. Сниппеты и clipboard
не добавлены в диагностический отчёт, логи или LLM glossary.

## Проверки и хвосты

- Native default: **608 passed, 0 failed, 7 ignored**, последовательный запуск
  с отдельным каталогом данных и закреплёнными Sherpa/ONNX DLL.
- V3: **327/327**; release/CI scripts: **48/48** в рабочем дереве. 20 cache tests
  относятся к отдельным изменениям владельца и не входят в этот коммит.
- Strict Clippy, CPU-only/minimal compilation, Rust fmt, frontend typecheck,
  lint, production build и version check прошли.
- Новые контракты: whole-utterance/question matching, disabled/default,
  однопроходные переменные и ленивый clipboard, отмена до чтения clipboard,
  versioned/strict/limited JSON, metadata и deep-copy roundtrip, отсутствие
  шаблонов в browser storage и сохранение списка после отключения.
- Browser mock: **720×560, 900×720, 1440×900**. Проверены создание, сохранение,
  редактирование/отключение записи, общий выключатель, удаление, отказ
  триггера-вопроса, явный JSON-экспорт и очистка записей после reload.
  Редактор прокручивается, footer доступен; горизонтального переполнения нет.
  Native JSON picker и реальная вставка этим не подтверждаются.

Локальные логи и screenshots — `build/checks/fono135-*`.
