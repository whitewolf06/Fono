# Дорожная карта Fono

Реализованные возможности и подтверждённые проверки находятся в
[STATUS](STATUS.md). Здесь — оставшаяся работа. Базовые сценарии, уже принятые
владельцем, не нужно каждый раз проходить заново без изменений в их коде.

## Ближайшая приёмка

- [ ] Проверить установку NSIS/MSI на чистой Windows без SDK и исходников:
      WebView2, ресурсы, первый запуск, сохранение данных и удаление приложения.
      Этот этап отложен владельцем.
- [ ] Проверить обновление установленной версии через подписанный канал:
      загрузку, версию, UAC, перезапуск, настройки/историю и ожидание активных операций.
- [ ] Пройти GUI/UAC онлайн-установщика, докачивание после обрыва и повторное
      использование проверенного кэша.
- [ ] Дополнить аппаратную матрицу: CPU-only, CUDA и Vulkan, AMD/Intel,
      недоступные runtime и драйверы, выбор Auto.
- [ ] Дополнить матрицу внешних полей: повышенные права, частичная отправка,
      Win+V, HTML/RTF. Отправка Ctrl+V сама по себе не доказывает принятие текста.
- [ ] Проверить длительные записи, реальные LLM-подключения и совместную
      работу API с интерактивной диктовкой.

Сценарии собраны в [QA](qa/README.md). Пользователь проверяет микрофон, hotkey,
окна и установку самостоятельно.

## Лира beta

Рабочая фиксированная фраза — «Привет, Лира». Владелец подтвердил повторные
пробуждения после возврата к проверенной схеме детектора. Следующая работа:

- [ ] Сокращать задержку по отдельным измерениям: фраза → detector → захват →
      сигнал готовности → overlay. После каждого изменения перепроверять обнаружения.
- [ ] Проверить независимые голоса и длинную обычную речь, похожие фразы,
      шум и разные расстояния до микрофона. Согласованные личные записи не
      превращать в публичный обучающий корпус.
- [ ] Проверить серии пробуждений, отмену, sleep/resume, hotplug, смену устройства
      и восстановление после ошибок worker.
- [ ] До изменения фразы или frozen operating point отдельно согласовать
      набор данных, пороги и критерии. Успешный короткий replay не закрывает recall
      и частоту ложных активаций.

Режим остаётся beta. Старый мастер произвольной RU/EN-фразы и режим «На лету»
не открываются вслед за Лирой. Контракт — в [wake-lira.md](wake-lira.md).

## Качество, стабильность и ресурсы

- [ ] Закрыть исходный PERF-04 без ослабления нулевого WER-допуска и подмены базы
      сравнения. Сохранять отрицательные результаты и независимый holdout.
      [История и данные](archive/improvement-plan/improvement-perf04.md).
- [ ] Снять p50/p95/p99 для начала записи, Stop → результат, LLM и вставки.
      Холодную загрузку и прогретый inference измерять отдельно.
- [ ] Длительный аппаратный soak: потоки, handles, private bytes, CPU,
      потерянные frames, 60 минут idle, 1000 циклов и реальные отказы GPU worker.
      Процессные fixtures остаются отдельным уровнем проверки.
- [ ] Измерить allocations и p99 audio callback после warmup, очереди и overflow.
- [ ] Проверить resident/adaptive на реальном давлении видеопамяти и без дребезга.
- [ ] Проверить миграцию старых settings/history и восстановление backup
      после прерванной записи в установленной версии.
- [ ] Развивать подсказки словаря для GigaAM/Parakeet и проверять качество
      терминов на согласованном наборе.
- [ ] Поддерживать advisory-проверки lockfile и согласовать регулярный gate
      по [политике зависимостей](dependency-policy.md).

Старые численные результаты, ограничения измерений и отчёты задач находятся
в [архиве](archive/README.md). Их наличие не закрывает текущую приёмку.

## Отдельные решения

- Новый потоковый вывод «На лету» требует собственного quality gate и
  явного решения о включении. Подтверждённый префикс должен оставаться неизменным.
- Миграция Vulkan-сборки и полный повтор GPU/protocol-матрицы —
  [ADR 0002](adr/0002-vulkan-cpp-worker.md).
- Linux/macOS требуют платформенных адаптеров hotkey, вставки, permissions,
  overlay, хранения и обновлений. Windows-поставка не подтверждает эти платформы.
- Расширение голосовых команд и свободный LLM Command Agent остаются отдельными
  задачами после стабилизации текущих границ.
