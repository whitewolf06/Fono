## ✅ Оптимизация производительности (ВЫПОЛНЕН)

Это был отдельный мини-этап, который дал радикальный буст.

**Проблема:** whisper работал RTF 5-8x (4 сек аудио = 20-34 сек обработки),
CPU показывал 0%.

**Причина найдена:** whisper.cpp собирался **без SIMD-инструкций**
(GGML_AVX2=OFF, GGML_FMA=OFF) и без `/O2`.

**Исправления:**
- [x] `.cargo/config.toml [env]`: GGML_NATIVE/AVX/AVX2/FMA/F16C=ON
- [x] CMAKE_C_FLAGS_RELEASE=/O2 /Ob2 /arch:AVX2
- [x] `num_threads`: 4 → 8 (clamp 2-8)
- [x] `opt-level`: "s" → 3 (оптимизация по скорости, не размеру)
- [x] `target-cpu=native` для Rust-кода
- [x] Параметры whisper: set_no_context, single_segment, print_progress=false

**Результат:**
| Модель | Было | Стало |
|---|---|---|
| base | 21 сек | ~1 сек |
| small | 34 сек | ~3 сек |
| medium | ~90 сек | ~8-10 сек |

## ✅ Этап 4 — Wake word «Эй, ассистент» (ВЫПОЛНЕН)

- [x] `wakeword/mod.rs`: WakeWordDetector с фоновым потоком
- [x] Архитектура whisper continuous: чанки 1.5 сек → tiny модель → поиск фразы
- [x] VAD-gating: пропуск тишины (экономия CPU)
- [x] Автозапуск при старте если включено в настройках
- [x] Полный цикл: wake → запись диктовки → STT (основная модель) → вставка
- [x] Переключение tiny ↔ основная модель
- [x] UI: индикатор статуса (Слушаю/Анализирую/Сработала), кнопки вкл/выкл
- [x] События wake-word-detected, wake-word-status во фронтенд

**Требует:** tiny модель (75 МБ) — скачивается в настройках.
**CPU в idle:** ~5-10%.
