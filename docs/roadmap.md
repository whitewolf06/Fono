# Roadmap Fono

Текущий статус: **v0.5.0-mvp** — рабочий MVP для Windows с push-to-talk,
wake word, AI-постобработкой, GPU-ускорением и выбором способа вставки текста.

---

## 🚨 P0 — hardening рабочего MVP

Подробный snapshot работающего MVP и порядок доработок: [MVP hardening plan](MVP_HARDENING_PLAN.md).

- [ ] Portable CPU release и тест MSI/NSIS на чистой Windows VM.
- [ ] `DictationCoordinator` и настоящая отмена операции.
- [ ] Приватность API-ключа/логов и надёжная text injection.
- [ ] Единый владелец аудиопотока вместо нескольких CPAL streams.
- [ ] CI и release smoke-test.

---

## ⏳ P2 — локальный Command Agent (LM Studio)

Цель: после явного префикса «команда» понимать свободные формулировки, но не
давать LLM произвольный доступ к Windows.

- [ ] `CommandRouter`: сначала быстрые локальные правила, затем fallback в LM Studio.
- [ ] Function calling / строгое JSON-действие: LLM выбирает только инструмент и
  валидированные аргументы; запуск shell, PowerShell и произвольных файлов запрещён.
- [ ] `set_volume(percent: 0..100)` через Windows Core Audio: «сделай громкость 20».
- [ ] Свободные варианты медиа-команд и управления громкостью: «чуть тише»,
  «примерно на половину», «включи следующий трек».
- [ ] `open_app(name)` и `focus_window(query)` только через пользовательский allowlist
  приложений и видимых окон.
- [ ] Подтверждение в overlay для рискованных действий (закрытие приложений,
  выключение ПК, отправка сообщений); безопасные действия выполняются сразу.
- [ ] Понятный результат/ошибка команды в overlay и логах.

> Обычная диктовка не интерпретируется как команда. Агент запускается только после
> явного «команда …» вслед за wake phrase или при отдельной горячей клавише команд.

- [x] Тестовая кнопка «Записать и распознать"

## ✅ Этап 2 — Текст-инъекция в окна

- [x] `injection/`: Win32 SendInput с KEYEVENTF_UNICODE
- [x] Поддержка русского, эмодзи, CJK
- [x] Режим вставки через буфер обмена (Ctrl+V) для приложений вроде Telegram
- [x] Push-to-talk: текст вставляется после отпускания Ctrl+Space

## ✅ Этап 3 — Push-to-talk + VAD

- [x] Глобальная горячая клавиша Ctrl+Space (press-to-talk)
- [x] `vad/`: energy-based VAD + `trim_silence`
- [x] Подсказка в UI: «Push-to-talk активен»
- [x] Ручная диктовка через кнопки Start/Stop

> **Примечание:** автоматическая остановка записи по тишине для push-to-talk
> сознательно **не реализована** — пользователь сам контролирует запись через
> зажатие/отпускание клавиши.
