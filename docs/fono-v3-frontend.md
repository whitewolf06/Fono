# Fono V3: визуальное согласование

## Запуск

Ветка `codex/fono-ui-v3`, отдельный вход `v3.html`.
`npm run dev:ui` → http://127.0.0.1:1420/v3.html#/

V3 работает только с демонстрационным runtime. Нативные команды, устройства, сеть API и реальные LLM не вызываются. Диктовка выдаёт подготовленный пример. Прослушивание синтетического образца запускается только нажатием пользователя.

## Карта

- `#/`: главная, быстрые настройки, последняя сессия.
- `#/history`: фильтры и архив.
- `#/trainer`: локальные демонстрационные наблюдения и рекомендации.
- `#/commands`: каталог, приложения, проверка фразы.
- `#/api/tasks`, `#/api/connection`: очередь и подключение.
- `#/settings/{section}`: general, audio, activation, processing, overlay, privacy, diagnostics.
- `#/onboarding`: пять шагов, возврат и продолжение позже.
- `#/overlay`: состояния подробного и компактного индикаторов.
- `#/scenarios`: воспроизводимые состояния и сброс демо.

## Устройство

`shared/domain/contracts.ts` содержит общие контракты портов, используемые несколькими фичами.
`app/mockWorkspace.ts` — composition root и единое реактивное состояние на срок жизни приложения.
Фичи разделены на domain, application, infrastructure, presentation; чистые правила остаются вне шаблонов.
UI обращается к внедрённым портам. Browser clipboard, storage, hotkey и focus находятся в адаптерах.
Тема установлена на html; диалоги и селекты WhiteUI в Teleport получают те же токены.

## Данные и изменения

Только разрешённые демонастройки переживают перезагрузку. История, ручной текст, инструкции и токены не сохраняются в браузере. Текущий результат независим от архива.
Выключатели применяются сразу; ожидание блокирует повторное действие, ошибка возвращает прежнее значение.
Остальные параметры используют общий черновик, сохранение, отмену и защиту несохранённых изменений.
Редактирование и улучшение меняют только текущий текст. Копируется видимый вариант. Новая сессия заменяет черновик.
Сценарии проверки сбрасывают текущие демонстрационные данные; загрузка и очередь могут быть зафиксированы для воспроизводимой проверки.

## Следующий этап: нативная интеграция

После визуального апрува подключить отдельные адаптеры к типизированному Tauri IPC.
Нужны новые или уточнённые контракты:

1. Управление включением API-сервиса, его состояние и ошибки переходов.
2. Улучшение произвольного черновика с отменой и идентификатором запроса.
3. Последний результат и исходная расшифровка текущей сессии независимо от сохранения истории.
4. Уровень сигнала 0..1, готовность устройств и стадии диктовки.
5. Подтверждение сохранения настроек, загрузка/отмена моделей, профили подключений.
6. Реальные тесты микрофона/фразы/подключения, доступность backend-ускорения.
7. Событие окончания должно содержать результат: текущий native stop может публиковать idle раньше записи истории.
8. Исходные расшифровки в архиве сохранять только с согласием на аналитику. Разделить архив и результат сессии.

Переключение основного окна, Rust pipeline, hotkey и настоящий overlay не входят в этот этап.

## Проверки

`npm run typecheck:v3`, `npm run lint`, `npm run build`, `npm run version:check`, `npm run format:check`.
Браузерная приёмка: 720×560, 900×720, 1440×900; клавиатура и фокус диалогов; настройки/save-error; диктовка/edit/improve/undo/copy; история; тренер; команды; очередь; первый запуск; overlay.
Результаты фактического прогона фиксируются в `docs/fono-v3-qa.md`. Браузерные проверки не подтверждают работу Tauri/Rust.
