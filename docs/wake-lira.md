# Пробуждение «Привет, Лира» — beta

Лира начинает обычную диктовку после фразы «Привет, Лира». Она работает локально
и включается по явному действию пользователя. В выпуске 0.8.0 нужный runtime и
модели входят в установщики Windows x64.

## Как пользоваться

1. Выберите микрофон и модель распознавания для обычной диктовки.
2. На главной в карточке «Пробуждение» или в настройках активации включите Лиру.
3. Дождитесь состояния «Слушаю» и произнесите «Привет, Лира».
4. Начинайте диктовать после звука готовности или появления индикатора.
5. Завершите диктовку обычным способом. После завершения операции Лира
   возвращается к ожиданию следующей фразы.

При ошибке индикатор должен показывать явное состояние остановки. Подробности
компактной ошибки доступны при наведении. Выключение пробуждения останавливает
его захват; смена микрофона требует нового включения.

Для запуска после перезапуска приложения снова включите пробуждение.
Форма записи и проверки образцов относится к debug-инструментам и в release
не отображается.

## Ограничения beta

- Между произнесённой фразой и готовностью к диктовке остаётся заметная задержка.
  Обнаружение фразы, открытие захвата и отрисовка overlay — разные этапы.
- Повторные пробуждения подтверждены владельцем. Это проверка одного голоса,
  а не готовая статистика для всех пользователей, устройств и шума.
- Длительные negatives и независимые голоса остаются в [roadmap](roadmap.md).
  Короткий replay не подтверждает час работы без ложных срабатываний.
- Удаление стартового обращения учитывает распознанные варианты
  «Привет, Лира / Лера / Ира» для сессии, начатой Лирой.
- Фраза фиксирована. Старые «Эй, Фоно» / «Hey Fono» и мастер произвольной
  фразы не включаются этим переключателем.

## Устройство и поставка

AudioHub передаёт ограниченный поток детектору. Отдельный worker использует
классификатор CNN и проверку T-one CTC; обычная диктовка проходит через тот же
контур STT и вставки, что и hotkey. Состояние «Слушаю» публикуется после
подготовки моделей и микрофона. При другой операции детектор может перейти
на паузу; интерфейс различает паузу, загрузку и ошибку.

Release-пакет содержит изолированный CPython, NumPy, ONNX Runtime CPU, модели
и notices. Версии и SHA256 закреплены в
[tools/wake-release/dependencies.json](../tools/wake-release/dependencies.json) и проверяются сборкой.
При включении проверяются manifest и файлы до открытия микрофона.
Системный Python и пути разработчика для release не используются; личные
dev-записи и обучающий корпус в пакет не входят.

контура — в [WAKE_WORD_ARCHITECTURE.md](WAKE_WORD_ARCHITECTURE.md), исторические
эксперименты — в [архиве](archive/improvement-plan/README.md).
