# FONO-136 — язык распознавания в overlay

Исходники v0.7.51, 21 октября 2026 года. Реализован F-09.1 из истории FONO-64.
База — v0.7.50 / `da418a2`. В актуальном `tasks.get_context` у FONO-136 нет
блокирующих dependency links. Использованы существующие overlay choice queue,
session snapshot, Stop flush, capture fence и STT scheduler.

## Поведение

- В режиме повторного нажатия с включёнными быстрыми настройками кнопка
  RU / EN / Авто открывает язык **распознавания** рядом с настройками обработки.
  Язык перевода остаётся отдельной настройкой. Подробный и компактный индикаторы
  используют один рабочий Vue-компонент.
- Native capability берётся из модели конкретной сессии. Управляемые
  многоязычные модели Whisper предлагают RU, EN, Авто; GigaAM показывает
  «Только RU», Parakeet — «Язык: авто», без обещания принудительного выбора.
  Для произвольного Whisper с неизвестной capability переключатель скрыт.
- Выбор сохраняется узкой транзакцией вместе с предпочтениями обработки,
  затем меняет snapshot точно указанной записи. Сохраняется и выбор для
  следующих диктовок. Профили приложений остаются прежними и применяются
  при следующем старте. При ошибке диска snapshot не меняется, UI возвращает
  подтверждённый выбор; Stop ждёт последний выбор или сообщает об ошибке.
- Проверяются модели и глобальных настроек, и текущей записи. Несовместимая
  смена глобальной модели не позволяет сохранить ложное обещание для следующей
  диктовки. После фиксации Stop, во время STT и в pending после STT менять
  язык нельзя. Старые запросы без нового поля сохраняют прежнее поведение.
- Сохранение дисковых настроек выполняется через `spawn_blocking`. Settings
  transaction, capture reservation и update admission lease принадлежат
  фактической работе, включая уход ожидающего IPC; публикация идёт после
  освобождения capture/pending locks. Поздний ответ не обновляет следующую сессию.
- Уже распознанный фрагмент содержит профиль языка. После смены языка прежний
  префикс отклоняется существующей проверкой и Stop распознаёт весь исходный PCM
  с новым языком. Это может увеличить время Stop длинной записи; текст разных
  языковых настроек не склеивается.
- Browser preview меняет только демонстрационные настройки. В настройках
  индикатора язык входит в черновик: Reset отменяет его, Save сохраняет.
  В browser storage остаются только разрешённые демонстрационные предпочтения.

## Проверки и хвосты

- Native default: **611 passed, 0 failed, 7 ignored**, последовательный запуск
  с отдельными данными и закреплёнными Sherpa/ONNX DLL. Strict Clippy,
  CPU-only/minimal compilation и Rust fmt прошли.
- V3: **331/331**. Release/CI scripts: **48/48** в рабочем дереве;
  20 cache tests относятся к отдельным изменениям владельца и в коммит не входят.
- Frontend typecheck, lint, production build, format/version и docs checks прошли.
  Новые проверки покрывают
  сохранение/rollback языка, ожидание последнего выбора перед Stop, поздний
  ответ предыдущей сессии, совместимость обеих моделей и отказ после STT,
  capability native/mock, Save/Reset черновика и сохранение предпочтений.
- Browser mock: **720×560, 900×720, 1440×900**, подробный/компактный вид,
  RU/EN/Авто и блокировка после начала распознавания. Горизонтального переполнения
  нет; выбранный язык не меняет язык перевода. Реальное аудио не использовалось.
