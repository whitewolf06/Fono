# FONO-125 — триггеры клавиатуры и мыши

Версия 0.7.40. Зависимость STAB-07 / FONO-87 реализована и находится
в `in_review`; её ручная Windows-приёмка остаётся отдельной проверкой.
Этот этап реализует F-04.1. CLI относится к FONO-126, выбор кнопки,
захват и проверка конфликтов в интерфейсе — к FONO-127.

## Реализация

В нативных настройках появилось поле `dictation_trigger`. Старые настройки
читаются с `shortcut`: обычное сочетание через RegisterHotKey остаётся
вариантом по умолчанию. Доступные значения:

| Значение                               | Удержание (`hold`)       | Повторное нажатие (`toggle`)                   |
| -------------------------------------- | ------------------------ | ---------------------------------------------- |
| `shortcut`                             | Прежнее сочетание клавиш | Прежнее одиночное повторное нажатие            |
| `right_alt`, `right_ctrl`, `caps_lock` | Запись до отпускания     | Двойное нажатие запускает или завершает запись |
| `x_button1`, `x_button2`               | Запись до отпускания     | Одно нажатие запускает или завершает запись    |

Для двойного нажатия первое удержание и интервал до второго нажатия
ограничены 350 мс. Автоповтор не считается новым нажатием. Второе
нажатие уже использованной пары не начинает следующую пару.

На Windows устанавливается только нужный хук: WH_KEYBOARD_LL для
модификатора или WH_MOUSE_LL для боковой кнопки. Message loop и нативные
ресурсы принадлежат отдельному потоку. Callback фильтрует выбранную
кнопку, отсекает автоповтор и помещает только её переход и tick timestamp
в ограниченную очередь из 64 событий. В callback нет IPC, открытия
микрофона, STT, оконных операций, файлов, логирования и блокирующих mutex.
Текст, scan codes, координаты мыши и нажатия остальных клавиш не сохраняются.
Синтетический ввод игнорируется, включая ввод самого Fono.

Отдельный worker передаёт события существующему lifecycle обычной диктовки.
Сохраняются operation_id, общий scheduler, ожидание сохранения настроек
оверлея перед Stop, обработка и защищённая вставка. Старый Release может
завершить только запись, начатую этим триггером. Установка хука при уже
зажатой кнопке ждёт её отпускания и нового нажатия.

Выбранные CapsLock и XButton поглощают свои физические Down/Up, чтобы
не переключать регистр и не отправлять браузеру Back/Forward. Начальное
состояние CapsLock не меняется. Right Alt / Right Ctrl пропускаются дальше.
При потере события очередь отключает триггер и запрашивает Cancel только
собственной записи; автоматического распознавания и вставки по ошибке нет.
После ошибки выбор триггера нужно применить заново. Уже поглощённый Down
остаётся согласован со своим Up даже при переполнении очереди.

При замене настроек прежние потоки останавливаются и присоединяются до
создания новых. При выходе UnhookWindowsHookEx и освобождение таймера
выполняются на owning thread до остановки pipeline. Ошибка подключения
очищает частичную регистрацию; существующая транзакция настроек возвращает
прежние настройки и регистрацию. Смена триггера запрещена во время операции.
Настоящая работа Start и очередь Stop/flush удерживают update admission
lease до своего завершения; ожидающий нажатия хук не блокирует обновление.

TypeScript IPC-тип синхронизирован. Сохранение обычных настроек из текущего
интерфейса сохраняет выбранный нативный триггер. Сам selector в UI появится
в FONO-127; browser mock не устанавливает системных хуков.

Основание для устройства потока и callbacks —
[LowLevelKeyboardProc](https://learn.microsoft.com/en-us/windows/win32/winmsg/lowlevelkeyboardproc),
[LowLevelMouseProc](https://learn.microsoft.com/en-us/windows/win32/winmsg/lowlevelmouseproc),
[UnhookWindowsHookEx](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-unhookwindowshookex).

## Проверки и оставшаяся приёмка

Автоматические проверки используют подставленные события выбранной кнопки.
Они не устанавливают глобальные хуки, не записывают микрофон и не нажимают
горячие клавиши в пользовательском приложении.

- 543 Rust-теста приложения прошли, 7 штатно ignored. Новые проверки
  покрывают whitelist ввода, синтетические события, CapsLock/мышиные пары,
  автоповтор, двойное нажатие и wraparound времени, старый Release,
  переполнение очереди, Cancel своей записи при ожидающем Stop, join worker,
  совместимость настроек и запрет смены триггера во время операции.
- 290 тестов V3 прошли, включая сохранение выбранного нативного триггера
  при правке остальных настроек. Это тесты адаптеров и mock/SSR, без
  аппаратной проверки Windows. Новых визуальных элементов нет; отдельные
  browser-сценарии на трёх размерах в этой задаче не выполнялись.
- 48 release/CI-проверок прошли; в них входят 20 ранее существовавших
  owner-проверок обслуживания кэша. Реальный удалённый Actions не запускался.
- Strict Clippy для всех targets, сборочные проверки CPU-only и без
  default features, Rustfmt, typecheck, lint, frontend build, синхронизация
  версии, format и ссылки документации прошли.

Первый Rust-прогон в песочнице дал 511 PASS и 31 отказ доступа к временным
файлам, ACL/junction и localhost fixtures. Повторный полный прогон с доступом
к этим ресурсам прошёл без изменения критериев. В рабочем дереве были
посторонние правки обслуживания кэшей и PERF-04; они не входят в коммит
FONO-125. Локальные логи — `build/checks/fono125-*.log`.

Владелец отдельно проверяет реальные Right Alt / Right Ctrl / CapsLock,
двойное нажатие, XButton1/2, удержание, Stop/Cancel в оверлее, переключение
сессий, начальный CapsLock on/off и выход с зажатой кнопкой. Быстрая печать,
AltGr/раскладки и фактическое снятие Windows-хуков остаются ручной приёмкой.
Микросекундная длительность реального callback ещё не измерена.

Выбор триггера и конфликты с командными сочетаниями требуют FONO-127.
До этого этапа альтернативные триггеры доступны только через типизированные
нативные настройки; автоматически они не включаются. Для ввода от AutoHotkey
и подобных программ предназначен следующий этап CLI / FONO-126.
WakeWord и live остаются выключены. Публикация, установка и перезапуск
пользовательского приложения в рамках этой задачи не выполняются.
