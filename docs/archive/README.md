# Архив разработки Fono

Здесь хранятся отчёты конкретных этапов, исходные измерения и прежние решения.
Они объясняют историю реализации и не описывают автоматически текущую версию.

- [План улучшений FONO-47](improvement-plan/README.md): этапы, задачи FONO,
  PERF-04 и эксперименты пробуждения; исходные JSON находятся рядом в
  `improvement-plan/evidence/`.
- [Прежний журнал STATUS](status-2026-10-26.md): накопленные записи до обновления
  документации 26 октября 2026 года.
- [Первоначальный проект CUDA-пакета](proposals/cuda-package-proposal.md):
  историческое предложение; действующая сборка — в
  [cuda-package-build.md](../cuda-package-build.md).

Текущие инструкции находятся в [общем указателе](../README.md), возможности
и открытые вопросы — в [STATUS](../STATUS.md), причины действующих решений —
в [ADR](../adr/README.md).

JSON-снимки перенесены без изменения байтов. Записанные внутри них пути, версии,
статусы и названия команд относятся к моменту измерения. Для прежнего
`docs/evidence/<имя>.json` новый адрес —
`docs/archive/improvement-plan/evidence/<имя>.json`.
Markdown-ссылки и потребители данных обновлены.

Новые рабочие прогоны сохраняйте в `build/`. Публикация нового измерения требует
проверки модели, корпуса, версии, происхождения данных и ограничений; не
подменяйте старый результат свежим запуском без явного пересмотра.
