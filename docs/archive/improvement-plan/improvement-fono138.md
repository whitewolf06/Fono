# FONO-138 — автостоп по тишине в toggle

Исходники v0.7.54, 21 октября 2026 года. База — v0.7.52 / `38a0ad5`.
Реализуется F-11.1 из истории FONO-66. В актуальном MCP-контексте FONO-138
нет отдельных блокирующих связей. Используются существующие AudioHub,
Silero VAD, lifecycle диктовки, barrier настроек overlay и типизированные порты.

## Поведение

- В «Настройки → Активация» для режима повторного нажатия появилась опция
  «Завершать запись по тишине»: выключено либо 2–10 секунд. По умолчанию
  выключено, в том числе при загрузке старых настроек. Hold не использует
  автостоп; выбор сохраняется для следующей toggle-диктовки.
- Настройка применяется после сохранения. Пока запись активна, менять её нельзя.
  Каждая запись получает свой снимок настроек. Язык интерфейса RU/EN, язык
  распознавания и параметры WakeWord хранятся независимо.
- Нативный потребитель читает тот же ограниченный PCM-буфер. Тишину определяет
  существующий речевой Silero VAD; таймер считает обработанные аудиосэмплы.
  Новая речь сбрасывает отсчёт. Потерянные данные не считаются тишиной.
  Статус и обратный отсчёт проходят через существующие snapshot/meter-порты.
- Автостоп действует только на обычную UI/hotkey-диктовку toggle. Голосовые
  команды, пробная диктовка, API-задания и WakeWord используют свои lifecycle.
  WakeWord и «На лету» остаются выключенными.
- Таймер сохраняет `operation_id`, ссылку на буфер и cancellation token до
  запуска фоновой работы. Cancel и следующая запись отзывают его полномочия.
  Работа Silero выполняется в blocking worker; coordinator и worker удерживают
  update admission lease до своего фактического завершения.
- Hotkey и автостоп используют общий completion gate и ждут сохранения
  последнего выбора overlay. Только один владелец выполняет Stop, STT,
  обработку и финализацию. Дубликаты получают сохранённый итог. Старый запрос
  не может заменить completion следующей записи. Ошибка сохранения оставляет
  запись доступной для ручного повтора Stop.
- Запись без речи тоже завершается после выбранного интервала. Финальная
  речевая проверка возвращает `NoSpeech` до STT, истории и внешней вставки.
  Исходный PCM не обрезается, правила обработки и сохранности поля сохраняются.
  При недоступном VAD автостоп сообщает об ошибке; завершить запись можно вручную.

В browser mock добавлен сценарий «Запись без речи» и демонстрация отсчёта.
Демонстрационные секунды не являются проверкой микрофона или качества VAD.
Заодно восстановлена возможность менять исходный демонстрационный текст
в существующем сценарии длинного содержимого после локализации FONO-137.

## Выполненные проверки

- Native default: **620 passed, 0 failed, 7 ignored**. Новые проверки покрывают
  диапазон настройки, изоляцию источников, сброс отсчёта, общий Stop,
  сохранённый итог, Cancel/новую запись и повтор после ошибки barrier.
- Реальный Silero VAD проверен на закреплённом публичном JFK WAV из тестовых
  fixtures: исходная громкость, коэффициент 0,12 и нулевой сигнал с добавленной
  тишиной. Речь сбрасывает отсчёт; нулевой сигнал даёт Stop после 32 256 сэмплов
  при пороге 2 секунды и окне 512 сэмплов. Этот короткий replay не измеряет
  качество на личном голосе, длительные паузы или ложные срабатывания в шуме.
- Полный V3-набор: **349/349**, включая восемь новых тестов настройки,
  сохранения, legacy-миграции, countdown, NoSpeech и запоздалых результатов.
- Release/CI scripts: **48/48** в рабочем дереве. Двадцать cache tests относятся
  к отдельным изменениям владельца и не входят в объём FONO-138.
- Frontend typecheck, lint, production build, format/version, docs check,
  Rust fmt, strict Clippy и minimal/CPU compilation без default features прошли.
  Логи находятся в `build/checks/fono138-*`.
- Browser mock: **18 комбинаций**, настройки активации, главная и overlay × RU/EN ×
  720×560, 900×720, 1440×900. Горизонтального переполнения основных областей нет.
  Проверены сохранение интервала, отмена изменения и перезагрузка страницы.
  Сценарий без речи завершился через 2 секунды с `NoSpeech`, сохранил предыдущий
  текст и не выдал ошибок. Screenshots и матрица — `build/checks/fono138-*`.

Native-набор и Clippy выполнены на v0.7.53. Продолжение v0.7.54 исправляет только
привязку браузерных `setInterval`/`clearInterval` в mock и обновляет отчёт:
реальный браузер обнаружил `Illegal invocation` у вызова таймера через объект.
После исправления повторно прошли весь V3-набор, typecheck, lint, build и
NoSpeech в браузере. Native-поведение при этом не менялось.
