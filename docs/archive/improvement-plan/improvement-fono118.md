# FONO-118 — квантованные Whisper

Результат подготовлен для ревью в версии 0.7.33. Зависимости FONO-113
(типизированный реестр) и FONO-108 / CI-03 находятся на ревью. Использованы
их реестр, проверка скачиваний и фиксированный публичный корпус.

## Что сделано

Добавлены Small Q5_1, Small Q8_0, Large v3 Turbo Q5_0 и Large v3 Turbo Q8_0.
Источник — [ggerganov/whisper.cpp на Hugging Face](https://huggingface.co/ggerganov/whisper.cpp/tree/5359861c739e955e79d9a303bcbc70fb988958b1),
ревизия `5359861c739e955e79d9a303bcbc70fb988958b1`. Точные размеры и LFS SHA256
проверены по API этой ревизии и после реального скачивания. Лицензия весов —
[MIT](https://github.com/openai/whisper/blob/main/LICENSE).
Веса и временные результаты находятся в игнорируемом `build/stt-quantized/`.

| Модель              |        Байт | Сокращение относительно соответствующей FP16 |
| ------------------- | ----------: | -------------------------------------------: |
| Small Q5_1          | 190 085 487 |                                        61,0% |
| Small Q8_0          | 264 464 607 |                                        45,8% |
| Large v3 Turbo Q5_0 | 574 041 195 |                                        64,7% |
| Large v3 Turbo Q8_0 | 874 188 075 |                                        46,2% |

Размер файла не является измерением занятой VRAM, скорости или качества.

Закреплённые метаданные находятся в
`src-tauri/resources/whisper-quantized-models.json`. Один manifest используется
native-каталогом и утилитой сравнения. Шесть старых размеров Whisper и их legacy
IPC сохранены; квантование имеет отдельную идентичность артефакта.

Общий STT IPC поддерживает скачивание, отмену, выбор и удаление новых моделей.
Сохраняются точные размер/hash, атомарная публикация, защита выбранного файла,
settings transaction и admission до завершения фонового I/O. Проверка
существующего файла перенесена внутрь blocking job; terminal download event
публикуется там же даже после отмены ожидающего IPC.

Миграция пути, JSON-настройки, preload/recovery и API сохраняют квантованный ID.
Неизвестные ID и несовпадение ID с именем файла отклоняются. Диагностика раскрывает
только закрытый список публичных идентификаторов. В V3 и browser mock видны
точные Q5/Q8-названия; обещаний отсутствия потерь качества нет.

## Проверка

Все четыре файла скачаны по HTTPS с закреплённой ревизии и проверены по размеру
и SHA256. Явный native-тест повторно установил каждый файл через production
`install_verified_model`, восстановил типизированные настройки из JSON,
загрузил модель в настоящий embedded CPU-runtime и проверил запрет удаления
выбранного файла. Тест прошёл; пользовательское приложение не запускалось.

В native-наборе 507 обычных тестов. При финальном общем прогоне один тест
повторного запуска fixture-worker превысил свой секундный handshake timeout;
отдельный повтор прошёл с тем же лимитом. Остальные 506 прошли в общем прогоне.
Пять проверок с внешними ресурсами/soak по умолчанию пропущены; новая проверка
четырёх артефактов явно запущена отдельно и прошла.

Пройдены 278 UI-тестов, 48 release/CI-контрактов, strict Clippy всех app targets,
CPU-only check, typecheck, lint, build, format и version check.
37 контрактных тестов проверили CI workflow, scorer, фиксированный корпус и
недопустимость подмены языка, PCM-длительности, декодирования и числа WAV.
Новые контракты подключены к workflow `stt-quality.yml`.

Браузерный mock проверен при 720×560, 900×720 и 1440×900: все четыре названия,
размеры и действия доступны, горизонтального переполнения нет. Это отдельная
проверка UI; она не подтверждает Tauri IPC, GPU или микрофон.

## Измерения и оставшаяся приёмка

Для сравнения подготовлена `scripts/stt-quantized-quality.mjs`: 20 закреплённых
FLEURS WAV (10 RU / 10 EN), исходный PCM 16 кГц, одинаковые fast / 8 threads,
Small FP16 и Turbo FP16 как соответствующие базы. Счётчик WER/CER дополнительно
пересчитывается независимым JS scorer. Лимит CI-03 сохранён: не более +1 п.п.
WER, отдельно для RU, EN и общего результата. PERF-04 и его исторические базы
не менялись.

Первый CPU-прогон остановлен до получения полной серии: в системе свободно
около 1,3 ГБ из 64 ГБ RAM, параллельно выполнялась сборка другого проекта.
Завершённых сопоставимых CPU-результатов нет. Полное прохождение CI-03, WER/CER,
RTF, cold/warm latency и утверждение об ускорении пока не подтверждены.
Критерии не ослаблены; повторять нагрузочные прогоны в этой среде не стали.

Отдельная проверка всех четырёх файлов через настоящий Vulkan-worker прошла:
protocol-3 handshake, load и распознавание публичного `en-01.wav` (10,56 с).
Все четыре результата совпали: WER 5,26%, CER 1,01% — `year` из эталона
распознано как `years`. Одного WAV недостаточно для вывода о качестве RU/EN.

| Модель              | Worker load, с | Первый decode, с | RTF одного WAV |
| ------------------- | -------------: | ---------------: | -------------: |
| Small Q5_1          |          1,039 |           15,705 |          1,487 |
| Small Q8_0          |          0,667 |            6,397 |          0,606 |
| Large v3 Turbo Q5_0 |          0,921 |            9,498 |          0,899 |
| Large v3 Turbo Q8_0 |          1,242 |            0,119 |          0,011 |

Это наблюдения совместимости на загруженной машине, по одному запуску без
FP16-базы и warm-серии. Большой разброс не позволяет рекомендовать вариант по
скорости или утверждать ускорение. Сырые ответы worker, policy и hashes —
[fono118-compatibility.json](evidence/fono118-compatibility.json).

Для повторения на свободной машине, после размещения шести файлов из manifest
в `build/stt-quantized/models` и сборки CPU-утилиты:

```powershell
cargo build --manifest-path src-tauri/Cargo.toml --locked --release -p fono-stt-worker --bin fono-stt-quality
node scripts/stt-quantized-quality.mjs src-tauri/target-codex-review/release/fono-stt-quality.exe build/stt-quantized/models build/stt-quantized/quality.json
```

Используйте `CARGO_TARGET_DIR=src-tauri/target-codex-review` и окружение сборки из
`docs/development.md`. Утилита сама проверяет hash всех моделей и WAV до замера.
Дополнительный аргумент пути Vulkan-worker проверяет handshake/load и один
публичный WAV для каждой новой модели. Флаг `--compatibility-only` запускает
только эту проверку и оставляет `quality_passed: null`.

CUDA для этих четырёх моделей, реальный HTTPS transfer через desktop IPC,
переключение в установленном приложении, личный голос, hotkey, overlay и чистая
Windows остаются отдельной приёмкой. Wire protocol 3 и worker-бинарники не
менялись. Публикация, installer и установка не выполнялись.
