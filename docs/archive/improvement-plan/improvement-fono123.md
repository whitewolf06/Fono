# FONO-123 — настройка предварительного распознавания

Версия 0.7.38, зависимость FONO-122 — коммит `73331e0` (0.7.37).
Работа подготовлена для ревью; качество реального распознавания длинных
записей остаётся отдельной задачей FONO-124.

## Реализация

В «Настройки → Аудио и распознавание» добавлен переключатель
«Распознавать фразы во время записи». Он применяется сразу через существующий
SettingsPort. Сохранение показывает pending, ошибка возвращает подтверждённый
выбор. Во время записи, обработки и ожидания решения переключатель недоступен;
тот же запрет действует в Rust под capture configuration fence.

`pretranscription_enabled` сохраняется в нативных настройках. Старые файлы
без этого поля читаются с `false`; явный выбор переживает повторное чтение.
В браузере сохраняется только демонстрационный boolean, без аудио и текстов.
Browser mock не запускает STT и прямо сообщает об этом в настройках.

По умолчанию настройка выключена. Исходный roadmap предлагал включение по
умолчанию, но карточка FONO-123 требует подтвердить дефолт по качеству.
До FONO-124 и ручной приёмки автоматическое включение не заявляется.

При явном включении классическая диктовка UI/hotkey использует consumer
FONO-121 и финализатор FONO-122. Порог — 240 000 сэмплов при 16 кГц
(15 секунд). До порога STT не вызывается; Stop короткой записи проходит
прежним путём распознавания всей записи, даже если ожидающий consumer уже
зарегистрирован. Командная и диагностическая запись consumer не запускают.
Live/WakeWord не включены; внешней вставки во время записи нет.

Состояние берётся из фактического worker: ожидание порога, ожидание паузы,
очередь scheduler, распознавание, fallback и количество готовых диапазонов.
Оно передаётся через существующие desktop snapshot и audio-level events,
без нового IPC-опроса. События проверяются по operation_id; после Stop они
не возвращают интерфейс к состоянию записи. Новая версия состояния
инвалидирует более старый асинхронный snapshot. Поля содержат только числа,
availability и перечисление состояния, без текста, PCM, путей и ошибок.
Сборки без speech-vad показывают недоступность и сохраняют обычный Stop.

Ограничения очереди, cancellation и admission leases из FONO-121/122
сохранены. Ошибка предварительной обработки оставляет исходную запись для
обычного распознавания после Stop.

## Проверки

- Новые native-проверки: совместимость старых настроек и roundtrip,
  запрет изменения во время операции, граница 239 999/240 000 сэмплов,
  фактические Waiting/Queued/Recognizing, отсутствие STT до порога,
  изоляция операции и сохранение всего PCM после сбоя.
- Для capture используются публичный JFK WAV, настоящий Silero и
  управляемый STT-распознаватель. Это проверка scheduler/lifecycle,
  а не WER реальной Whisper-модели.
- 285 тестов V3 и 48 release/CI-проверок прошли. Дополнены проверки
  сохранения/pending/отката, старых настроек, активной операции,
  запоздалых событий и SSR настоящего Vue/WhiteUI-переключателя.
  После последней mock-правки отдельно прошли 22 mock UI-теста, включая
  новый сценарий сохранения выбора и отката, если запись обогнала сохранение.
- TypeScript, lint, frontend build, version/format/docs checks успешны.
- Итоговый прогон после правки короткой записи: 527 native-тестов прошли,
  6 штатно ignored. Strict Clippy, Rustfmt, CPU-only и no-default-features
  compilation checks прошли. После Cargo выполнен `cache:maintain`.

Логи находятся локально в `build/checks/fono123-*.log`. Проверяется текущее
рабочее дерево, включая ранее существовавшие правки обслуживания кэша;
эти сторонние изменения в коммит FONO-123 не входят.

## Хвосты

- FONO-124: WER и задержка Stop → текст на длинных записях с реальными
  моделями/GPU, влияние контекста и решение о дефолте. Новых STT-бенчмарков
  эта задача не добавляет, критерии качества не меняет.
- Browser-проверка 720×560, 900×720 и 1440×900 не выполнена: инструмент
  отказал в доступе к вкладке по URL policy. Проверка через альтернативную
  поверхность не выполнялась; временные dev-серверы остановлены.
- Голос, hotkey, поля и native overlay проверяет владелец. Микрофон и
  пользовательское приложение автоматически не запускались.
- Remote CI, installer, публикация и установка не выполнялись.
