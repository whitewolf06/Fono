# FONO-142 — повторная проверка замороженного WakeWord

Исходники v0.7.58, 21 октября 2026 года. База — v0.7.57 / `c625f03`.
Источник — W-01 из `improvement-plan/03-wake-word.md`.
Зависимость ARC-01 / FONO-88 уже реализована и находится в `in_review`;
выделение AudioHub и Silero VAD в `fono-audio` выполнено раньше.

## Сохранённый результат первого этапа

Задача уже была выполнена в `3a024c8` / v0.7.9. Повторная проверка
подтвердила отсутствие `fono-wake` в default normal dependency tree,
удаление Whisper Experimental, старых фраз и smoke-скрипта. В bundle
resource manifest нет wake-моделей. Silero VAD и его runtime остаются
для обычной диктовки. Флаги Rust и V3 остаются `false`, документация
помечена замороженной, пользовательские настройки и модели не удаляются.

Исследовательские RU/EN streaming backend остаются за выключенными
features, как зафиксировано при первом этапе. Возврат детектора
и измерение его качества относятся к отдельным задачам.

## Найденная и исправленная регрессия

Полное обновление `createNativeContext.refresh()` безусловно вызывало
`get_wake_word_capabilities` и `get_wake_word_status`. В обычной сборке
эти команды исключены из Rust handler, поэтому их отказы могли попадать
в ошибку и журнал интерфейса при запуске или обновлении настроек.

Оба чтения теперь находятся за тем же compile-time флагом
`__FONO_WAKE_WORD__`, что остальные wake-порты. Сохранены очереди,
проверки видимости и поколения запроса; обычные чтения настроек,
моделей, устройств, истории и сервиса продолжают работать.

Новый тест полного native refresh сначала воспроизвёл два лишних IPC,
затем прошёл в общем наборе. Production build проверен отдельно:
в **19 JS-файлах нет ни одной из 15 WakeWord-команд**. Это проверка
собранного frontend, а не только исходного условия.

## Проверки

- V3 — **364/364**, включая новый тест startup refresh.
- Native — **631 passed, 0 failed, 7 ignored**. Audio —
  **44 passed, 0 failed, 1 ignored**. Отдельно перед исправлением
  прошли 15 проверок совместимости wake-настроек на базе v0.7.57:
  старое включение выключается, фраза/hotkey/backend сохраняются,
  stale settings delta не возвращает пробуждение.
- Feature/CI contracts — **11/11**. Release/CI scripts — **48/48**
  в рабочем дереве, включая 20 отдельных cache tests владельца,
  которые в этот коммит не входят.
- Typecheck, lint, production build и strict Clippy прошли.
- Browser mock — **6 сценариев**: RU/EN × 720×560, 900×720, 1440×900.
  В выборе активации шесть обычных кнопок/сочетаний, WakeWord отсутствует.
  Горизонтального переполнения и ошибок консоли нет.

## Оставшаяся приёмка

Владелец проверяет обычную диктовку в Windows по
[методике](../../qa/dictation-controls.md): запуск без ошибки отсутствующей
команды, hold/toggle, завершение и сохранение результата.
Микрофон, пользовательское приложение и tray агентом не проверялись.
Installer не пересобирался, установка, публикация и удалённый CI
не выполнялись. Статус `in_review` сохраняет эту границу приёмки.

Recall, false activations и личный голос не являются проверкой W-01:
WakeWord остаётся замороженным, а стенд качества — следующая FONO-143.
