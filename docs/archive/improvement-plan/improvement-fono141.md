# FONO-141 — локальные подключения Ollama и LM Studio

Исходники v0.7.57, 21 октября 2026 года. База — v0.7.56 / `4ac2a84`.
Источник — F-14 из `improvement-plan/02-features-roadmap.md`, история FONO-69.
У задачи нет блокирующих зависимостей. Используются существующие LLM-порты,
клиент OpenAI-compatible API и сохранение настроек Rust.

## Что сделано

- В форме нового подключения доступны шаблоны Ollama и LM Studio.
  Они подставляют название, провайдера, локальное расположение и адрес:
  `http://127.0.0.1:11434/v1` или `http://127.0.0.1:1234/v1`.
  ID модели остаётся пустым до выбора пользователя. Шаблон очищает ключ
  черновика; существующий профиль с сохранённым ID шаблоном не заменяется.
- Выбор шаблона ничего не отправляет и не сохраняет. Отдельная кнопка
  «Проверить сервер и найти модели» вызывает прежнюю IPC-команду
  `list_llm_profile_models` с одним из двух встроенных `localPreset`.
  Вызов по `profileId` продолжает работать для сохранённых подключений.
- Новый путь использует анонимный `GET /models`: без текста, генерации,
  ключа и чтения credentials vault. Действуют прежние ограничения клиента:
  timeout 3 секунды и максимум 2 МиБ ответа. Update activity lease
  удерживается до завершения запроса.
- Форма различает проверку, доступный список, пустой список и ошибку.
  Ошибка сервера не меняет сохранённые профили и предпочтения диктовки.
  Можно повторить проверку или ввести ID вручную. Смена адреса, провайдера,
  расположения или шаблона сбрасывает список; поздние ответы не возвращают
  его после смены формы или закрытия.
- Модель выбирается явно из фактических ID ответа; первая модель сама
  не назначается. «Сохранить профиль» использует штатное сохранение, затем
  подключение выбирается обычным селектором обработки и кнопкой раздела.
  Сохранение профиля не требует работающего сервера.
- Подписи доступны на русском и английском. Browser mock явно показывает
  демонстрационные ID, не обращается к локальным серверам и держит профили
  только до перезагрузки страницы.

Адреса и формат поиска сверены с официальными документами
[Ollama](https://docs.ollama.com/api/openai-compatibility) и
[LM Studio](https://lmstudio.ai/docs/developer/openai-compat/models).
Наличие ID в списке не подтверждает загрузку модели, успешную генерацию
или качество русского редактирования.

## Проверки

- V3 — **363/363**. Пять новых тестов проверяют шаблоны, отсутствие
  автоматического запроса, пустой/недоступный сервер, повтор, поздние ответы,
  совместимость IPC и отсутствие изменений сохранённых предпочтений.
- Native — **631 passed, 0 failed, 7 ignored**. Аудиоядро —
  **44 passed, 0 failed, 1 ignored**. TCP fixture подтверждает только
  `GET /v1/models`, без Authorization и тела. Реальные Ollama и LM Studio
  в этом прогоне не запускались.
- Typecheck, lint, production build, strict Clippy и minimal/CPU compilation
  прошли. Release/CI scripts — **48/48** в рабочем дереве; двадцать cache
  tests относятся к отдельным изменениям владельца и в коммит не входят.
- Browser mock — **12 сценариев**: RU/EN × Ollama/LM Studio × 720×560,
  900×720, 1440×900. Проверены списки и выбранные ID, сохранение обоих
  профилей, выбор Ollama для обработки и ручной ввод ID. Горизонтального
  переполнения и ошибок консоли нет. Высокая форма прокручивается.

Итог проверок — [JSON](evidence/fono141-validation.json).

## Оставшиеся критерии

Измеренных рекомендаций моделей для русской «Очистки» в проекте нет.
Поэтому рейтинг и конкретные названия не добавлены: нужна отдельная
сравнимая проверка сохранения смысла, выдумок и задержки на согласованном
корпусе. Текущая подсказка предлагает небольшую instruct-модель для первой
пробы и прямо сообщает об отсутствии замеров.

[Ручная приёмка](../../qa/local-llm-presets.md) остаётся для настоящих локальных
серверов, авторизации, генерации и сохранения после перезапуска desktop.
Эта часть и измеренные рекомендации не объявлены выполненными.
Микрофон, пользовательское Fono, installer, публикация и удалённый CI
в этом этапе не использовались.
