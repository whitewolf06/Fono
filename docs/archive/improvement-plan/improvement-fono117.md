# FONO-117: выбор моделей и фактические метаданные

Задача: [FONO-117](https://kvorum.gorbach-dev.ru/tasks/FONO-117/f-01-5).
Основа — FONO-113/114 и CPU backend FONO-115 с сегментацией FONO-116.

## Сделано

- Каталог V3 разделён на Whisper, GigaAM и Parakeet. Карточки показывают размер
  пакета, лицензию, языки, пунктуацию и доступное ускорение. Рекомендаций о
  сравнительном качестве без измерений нет.
- Native загрузка использует закреплённые ревизии и точные размеры/SHA256
  каждого файла. Незавершённый пакет остаётся в собственном staging-каталоге.
  Публикация всего пакета атомарна на Windows; существующий пакет не заменяется.
  Ошибки, отмена, проверка и суммарный прогресс доходят до интерфейса. Удаление
  выбранной модели запрещено. Атрибуция сохраняется вместе с пакетом.
- Настройки хранят типизированный `ModelId` и локальный путь. Для offline-моделей
  `whisper_model_path` остаётся пустым. Старые настройки Whisper, custom-файлы
  и несвязанные сохранения устаревшей формы сохраняют совместимость.
- Выбор в V3 проходит через native подготовку модели и сохранение. После
  перезапуска модель загружается тем же типизированным путём. Ошибка до
  сохранения возвращает прежнюю модель. Admission и транзакция остаются у
  фонового исполнителя до фактического завершения, включая отменённый IPC.
- Для GigaAM/Parakeet доступны Авто и CPU. Язык модель определяет внутри
  поддерживаемого набора; принудительный выбор языка не обещается. Настройки
  Whisper и CUDA-панель скрываются; предпочтения Whisper сохраняются для возврата.
- Основная диктовка, команды, пробная диктовка и API принимают новые модели.
  API использует неперекрывающиеся VAD-сегменты, checkpoint retry и общий scheduler.
  Смена настроек модели во время API/интерактивной работы блокируется.
- История хранит recognizer и публичный ID модели из снимка сессии, фактический
  backend из результата и отдельно запрошенное ускорение. Старые записи без
  новых полей поддерживаются; пути пакетов и выдуманный detected language не
  попадают в метаданные.

## Проверка

Полный native-набор: 506 прошли, 4 явных проверки с внешними моделями/soak
по умолчанию пропущены. Новый тест обоих offline-пакетов запущен отдельно
и прошёл. Полный UI-набор: 276 прошли; после финального исправления выбора
при пустых настройках — ещё 35 целевых native-adapter UI-тестов без ошибок.
Release/CI-контракты: 48 прошли. Пройдены сборка Vue, typecheck, lint,
форматирование, проверка локальных ссылок и синхронизации версии.
Strict Clippy для всех app targets и сборки без default features / CPU-only
также прошли. Ошибки PermissionDenied на hard-link в ограниченной песочнице
проверены повторным успешным запуском того же native-набора вне неё.

Unit/native проверки покрывают миграцию, stale delta, совместимость настроек,
границы размера скачивания, целостность и атомарную публикацию пакета, отмену,
защиту выбранного пакета и метаданные сессии. UI-проверки покрывают типизированный
download/cancel IPC, переключение модели и ограничения языка/ускорения.

Явный `installed_packages_roundtrip_settings_and_recognize_public_wav`
проверил оба полных пакета: читает ранее скачанные закреплённые артефакты как
поток, устанавливает с полной проверкой, восстанавливает настройки из JSON,
загружает настоящий CPU recognizer и распознаёт публичный FLEURS `ru-01.wav`.
Проверены readiness, непустой результат, модель и фактический CPU в метаданных.
Это проверка native кода на WAV; Tauri UI и микрофон в ней не запускаются.

Браузерный mock проверен отдельно при 720×560, 900×720 и 1440×900: группы моделей,
загрузка GigaAM/Parakeet, сохранение выбора, доступные настройки, защита выбранной
модели. Горизонтального переполнения документа и строк моделей нет.

## Хвосты

- Сравнение WER/CER/RTF и рекомендации качества — FONO-119. На контрольной фразе
  Parakeet сохраняет ранее наблюдавшуюся ошибку «Каждый этап» → «Каждые тап».
  Подстройки декодера и новые циклы измерений в FONO-117 не выполнялись.
- Непрерывная речь на принудительных границах 25 секунд требует дальнейшей
  проверки качества. Семантика сегментации FONO-116 не менялась.
- Реальный HTTPS transfer через IPC, переключение в установленном приложении,
  личный голос, hotkey, overlay и чистая Windows остаются ручной приёмкой.
  Локальный тест установки использовал уже проверенный кэш, без повторного
  скачивания около 900 МБ из интернета.
- Сетевое чтение отменяется между блоками; уже заблокированный сетевой read или
  native decode заканчивается своим таймаутом/вызовом. Admission в это время
  сохраняется. Докачивание multi-file пакетов не добавлено.
- Публикация каталога offline-пакета рассчитана на Windows. Квантованные
  Whisper остаются FONO-118. GPU для новых движков в этой сборке недоступен.

Результат предназначен для ревью. Публикация, installer и установка не выполнялись.

Локальная версия — 0.7.32, ветка `codex/fono117-model-settings-20261019`.
Синхронизация с Кворумом выполнена через MCP: один итоговый комментарий
`ccb113b3-faf4-46f0-89fc-d152e7884967`, статус задачи — `in_review`.
Текст комментария и статус подтверждены отдельным чтением после записи.
