# Fono V3 — нативное обновление 0.5.16

> **Исторический отчёт от 2 октября 2026 года, версия 0.5.16.** Ниже сохранён снимок первого нативного подключения V3 и выполненных тогда проверок. Он не описывает текущие возможности и ограничения Fono: в частности, WakeWord теперь временно недоступен, а режимы горячей клавиши и индикатор изменились. Актуальные архитектура и статус — [architecture.md](architecture.md) и [STATUS.md](STATUS.md); текущий фронтенд — [fono-v3-frontend.md](fono-v3-frontend.md). Числа тестов и сведения о запуске ниже относятся только к этому историческому этапу, а не к текущей приёмке.

## Состав

- Основное окно и настоящий плавающий индикатор переключены на Vue V3 / WhiteUI 0.6.0.
- В Tauri используется native runtime; обычный браузер сохраняет демонстрационный режим.
- Устройства, настройки, модели распознавания, история, API-очередь и диагностика читаются через Rust IPC.
- Пробуждение включается через существующий lifecycle ядра. Смена микрофона обновляет wake-конфигурацию.
- Списки моделей ИИ загружаются из выбранного подключения; доступен ввод точного ID. Ключи сохраняются через Windows Credential Manager.
- Последняя диктовка и её исходная расшифровка доступны в памяти сессии независимо от сохранения истории. Правки и повторное улучшение не перезаписывают архив. Запоздалый ответ ИИ не заменяет новую диктовку.
- Запись кнопкой главной возвращает текст в редактор Fono. Hotkey работает при удержании и вставляет текст в активное внешнее окно; wake использует существующее завершение по тишине.
- Отдельный контроллер запускает и останавливает API-сервис. Отключение при активных задачах отклоняется с понятной ошибкой.
- Сохранены исправления восстановления позиции индикатора, проверка координат, отключение, предпросмотр и сброс.
- Добавлен настоящий автозапуск для текущего пользователя Windows.

## Данные и совместимость

Идентификатор приложения и каталог пользовательских данных не менялись. Поле service_enabled по умолчанию включено для старых настроек. Версия Fono синхронизируется штатным скриптом. Существующие модели и LLM-профили читаются без преобразования пользовательских файлов во фронтенде.

Проверки разработки используют отдельный абсолютный FONO_TEST_DATA_DIR и порт FONO_API_PORT. Этот каталог работает только в debug. В нём нельзя читать, изменять или удалять настоящие Windows credentials и менять автозапуск.

## Проверки

- Vue TypeScript и production-сборка — пройдены.
- V3: 19 тестов (11 browser mock и 8 native adapter) — пройдены.
- Rust: 123 теста основной библиотеки — пройдены.
- Debug-приложение запущено с изолированными настройками, API health на отдельном порту ответил ready.
- Визуальную и функциональную проверку основного окна, микрофона, wake и overlay пользователь выполняет самостоятельно. По его просьбе дальнейшее управление окнами агентом прекращено.
- Установщик готовится отдельно; установка автоматически не выполняется.

Для сборки используется закреплённый submodule whisper.cpp. Предварительный тестовый запуск обнаружил отсутствующий submodule в worktree; после его инициализации все Rust-тесты прошли.
