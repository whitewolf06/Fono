# Как тестировать WhisperClone

Текущий статус: **Этап 0 завершён** (скаффолд собирается и запускается).
Полный цикл «голос → текст» — в разработке (Этапы 1-3).

Эта инструкция описывает, что можно проверить уже сейчас.

## Шаг 0. Сборка и запуск

```bash
# Из корня проекта
npm run tauri build -- --no-bundle
# или для dev-режима с горячей перезагрузкой:
npm run tauri dev
```

Исполняемый файл появится в `src-tauri/target/release/whisperclone.exe`.

> ⚠️ Переменные окружения для сборки (нужны на вашей машине):
> ```bash
> export PATH="/c/Users/0whit/.cargo/bin:/c/Program Files/CMake/bin:$PATH"
> export LIBCLANG_PATH="C:/Program Files/LLVM/bin"
> ```

Запустите exe — должно появиться окно настроек и иконка в трее.

## Что можно проверить прямо сейчас

### 1. ✅ UI работает корректно

- [ ] Окно настроек открывается, все секции видны
- [ ] Onboarding wizard доступен по URL `index.html?view=onboarding`
  (можно проверить в devtools или временном окне)
- [ ] Иконка в системном трее видна, меню открывается
- [ ] Пункт «Открыть настройки» из трея показывает окно
- [ ] Пункт «Выход» из трея закрывает приложение
- [ ] Тема тёмная, шрифты читаемы, нет визуальных багов

### 2. 🎙️ Микрофон определяется

- [ ] В разделе «Микрофон» откройте выпадающий список
- [ ] Должны увидеть ваши физические устройства ввода
- [ ] Текущее системное устройство помечено как «(default)»

**Если список пуст** — проблема с разрешениями микрофона в Windows:
`Settings → Privacy → Microphone → Allow apps to access your microphone`.

### 3. 📥 Whisper-модель скачивается

- [ ] В разделе «Модель распознавания» нажмите «Скачать» у **base** (~147 МБ)
- [ ] Дождитесь завершения (может занять 1-3 минуты)
- [ ] Статус должен поменяться на «✓ Скачана»
- [ ] Нажмите «Выбрать» — модель активируется

**Файлы моделей лежат в:** `%APPDATA%\WhisperClone\whisper-models\`

### 4. 🧪 LM Studio подключается (опционально)

Если у вас запущен LM Studio:

1. Откройте LM Studio → загрузите модель (напр. Qwen2.5-7B-Instruct)
2. Включите **Local Server** на порту 1234
3. В WhisperClone → «AI-обработка» → «Проверить соединение»
4. Должны увидеть: `✓ LM Studio активен, модель: <имя>`

Без LM Studio — оставьте режим «Выключено» или «Чистка», будет работать «сырая» транскрипция.

### 5. 💾 Настройки сохраняются

- [ ] Измените любое поле (язык, hotkey, модель)
- [ ] Нажмите «Сохранить»
- [ ] Перезапустите приложение
- [ ] Изменённые значения должны сохраниться

Файл настроек: `%APPDATA%\WhisperClone\settings.json`

## Что НЕ работает (ожидаемо на этом этапе)

Эти функции в разработке — не считайте их багами:

❌ **Push-to-talk (`Ctrl+Space`)** — горячая клавиша ещё не зарегистрирована
❌ **Wake word («Эй, ассистент»)** — в разработке (Этап 4)
❌ **Текстовая транскрипция** — нет UI-кнопки «записать и увидеть результат»
❌ **Вставка текста в окна** — функция injection реализована, но не вызывается
❌ **Overlay-индикатор** показывается только при смене состояния (которой пока нет)

---

## Как сообщить о проблеме

При возникновении ошибок соберите:

1. **Логи приложения** — запустите exe из консоли:
   ```bash
   ./src-tauri/target/release/whisperclone.exe 2>&1 | tee app.log
   ```
2. **Скриншот** окна с ошибкой.
3. **Версия Windows** (`winver`).
4. **Содержимое** `%APPDATA%\WhisperClone\settings.json`.

## Что будет проверяться на следующих этапах

### Этап 1: Audio + STT
- [ ] Кнопка «Записать 5 сек» → транскрипт виден в UI
- [ ] Распознавание русского / английского корректно
- [ ] Задержка < 2 сек на short phrase

### Этап 2: Текст-инъекция
- [ ] Вставка в Notepad, Word, браузер, Telegram работает
- [ ] Кириллица и эмодзи вставляются без искажений

### Этап 3: Push-to-talk MVP
- [ ] Зажать `Ctrl+Space` → запись стартует, overlay горит красным
- [ ] Отпустить → транскрипция → вставка
- [ ] Полный цикл < 3 сек

### Этап 4: Wake word
- [ ] Сказать «Эй, ассистент» → запись стартует без нажатий
- [ ] CPU в IDLE < 5%

### Этап 5: AI-обработка
- [ ] Сказать «надо отправить жене что задержусь» → вставлено аккуратное сообщение
