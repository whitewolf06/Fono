# Как тестировать WhisperClone

Приложение находится в стадии **рабочего MVP**. Ниже — чек-лист ручного тестирования
основных сценариев.

## Шаг 0. Сборка и запуск

```bash
# Релизная сборка (без упаковки):
npm run tauri build -- --no-bundle

# Или dev-режим с горячей перезагрузкой:
npm run tauri dev
```

Исполняемый файл появится в:

```
src-tauri\target\release\whisperclone.exe
```

> При ошибке `Отказано в доступе` убейте запущенный процесс:
> ```bash
> cmd //c "taskkill /F /IM whisperclone.exe"
> ```

## Что можно проверить

### 1. ✅ UI и настройки

- [ ] Окно настроек открывается, все секции видны.
- [ ] Иконка в системном трее видна, меню открывается.
- [ ] Пункт «Открыть настройки» показывает окно.
- [ ] Пункт «Выход» закрывает приложение.
- [ ] Изменения настроек сохраняются после перезапуска.

Файл настроек: `%APPDATA%\WhisperClone\settings.json`

### 2. 🎙️ Микрофон

- [ ] В разделе «Микрофон» открывается список устройств.
- [ ] Выбор устройства работает.
- [ ] Тест микрофона показывает уровень.

### 3. 📥 Whisper-модель

- [ ] В разделе «Модель распознавания» скачайте **base** (~147 МБ).
- [ ] Статус меняется на «✓ Скачана».
- [ ] Нажмите «Выбрать».

Модели хранятся в: `%APPDATA%\WhisperClone\whisper-models\`

### 4. 🧪 Тест транскрипции

- [ ] В разделе «🧪 Тест транскрипции» нажмите «Записать и распознать».
- [ ] Распознанный текст появляется в окне.
- [ ] Включите «Вставлять в активное окно» — текст вставляется в другое приложение.

### 5. ⌨️ Push-to-talk

- [ ] Зажмите `Ctrl+Space` (или выбранный hotkey) — overlay показывает «Слушаю…».
- [ ] Скажите фразу.
- [ ] Отпустите клавишу — текст вставляется в активное окно.

### 6. 🗣️ Wake word

- [ ] В разделе «Активация» включите «Активация по ключевой фразе».
- [ ] Убедитесь, что скачана модель **base**.
- [ ] Скажите фразу (по умолчанию «Эй, ассистент»).
- [ ] Overlay показывает «Сработала!», начинается запись.
- [ ] Скажите текст, замолчите — запись остановится и текст вставится.

### 7. ✨ AI-обработка

- [ ] Запустите LM Studio, включите Local Server на порту 1234.
- [ ] В WhisperClone выберите режим «Чистка».
- [ ] Нажмите «Проверить соединение» — должно появиться имя модели.
- [ ] Сделайте диктовку с «ээ»/«мм» — результат должен быть очищен.

### 8. 💾 Режимы вставки

- [ ] В разделе «⚙️ Прочее» выберите «SendInput».
- [ ] Диктовка работает в Notepad / Word / браузере.
- [ ] Выберите «Буфер обмена».
- [ ] Диктовка работает в Telegram Desktop и других защищённых приложениях.

## Как сообщить о проблеме

При возникновении ошибок соберите:

1. **Логи приложения** из `%APPDATA%\WhisperClone\logs\`.
2. **Скриншот** окна с ошибкой.
3. **Версия Windows** (`winver`).
4. **Содержимое** `%APPDATA%\WhisperClone\settings.json`.
