# Форма обратной связи Fono

Fono открывает публичную форму Feedback в браузере по кнопке «Обратная связь» в
сайдбаре или в настройках диагностики. В приложение не добавляется SDK отправки,
автоматическое создание отчётов или фоновая передача данных.

## Настройка канала

Единый конфиг для Vue и Rust — `src-tauri/feedback-channel.json`:

```json
{
  "publicFormUrl": ""
}
```

Пустое значение оставляет канал выключенным. После создания реального Source и
включения публичной формы в Кворуме владелец задаёт его URL в формате
`https://<host>/feedback/submit/<source-uuid>` и пересобирает Fono.
В конфиге хранится только публичный адрес, без секретов. Query, fragment,
credentials, произвольные страницы и другие схемы запрещены. Для debug-сборки
допускается HTTP только на localhost, 127.0.0.1 или ::1; release требует HTTPS.
Изменение этого файла не включает публичный приём на сервере.

Native IPC `open_feedback_form` доступен только окну `settings`, принимает
только `includeContext` и сам читает проверенный конфиг. Используется существующий
Windows ShellExecuteW, без запуска shell-команды и дополнительных разрешений
opener. Browser mock работает через внедрённый адаптер.

## Контекст и приватность

Переключатель «Добавить версию и раздел Fono» выключен при каждом открытии
страницы и не сохраняется. При явном включении в fragment формы передаются
только `version`, `platform` и фиксированный `route=/settings/diagnostics`.
Поля видны до открытия формы; в веб-форме их нужно отдельно проверить и разрешить.
Fragment не является доверенным источником или основанием для авторизации.

Тексты диктовок, аудио, журнал, ошибки, ключи, инструкции, история, словарь,
пути, адреса подключений и имена устройств не передаются. Диагностический
отчёт остаётся отдельным локальным действием пользователя.

## Проверка

Общий прогон после завершения пакета:

```powershell
npm run typecheck:v3
npm run lint
npm run build
npm run test:v3
npm run test:release
npm run format:check
npm run version:check
cargo test --manifest-path src-tauri/Cargo.toml --lib feedback
```

Автоматические проверки подменяют открытие браузера и проверяют безопасный URL,
выключенный канал, явное согласие, состав IPC и запрет для другого native-окна.
Открытие реальной формы из Windows-сборки и отправку сообщения проверяет
пользователь отдельно. Сборка, локальный коммит, push и релиз — отдельные этапы.
