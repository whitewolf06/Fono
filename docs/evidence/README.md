# Лицензии и действующие ссылки на данные

Датированные JSON-результаты перенесены в
[архив плана улучшений](../archive/improvement-plan/README.md).
Исторические числа не являются текущей приёмкой.

В `licenses/` сохранены notices моделей и использованных корпусов.
[offline-stt-NOTICE.md](licenses/offline-stt-NOTICE.md) включается в Rust через
`include_str!`; его путь и содержимое остаются частью рабочего контракта
поставки. Атрибуция исходных наборов сохраняется и после переноса отчётов.
