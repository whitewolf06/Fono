# ADR 0002: текущая реализация Vulkan worker

Дата фиксации: 17 октября 2026 года. Статус: временное решение; исследование ARC-08 открыто.

## Контекст

CUDA worker собирается из Rust crate `fono-stt-worker`, Vulkan — из C++-проекта `fono-stt-vulkan-worker` через CMake и закреплённый `vendor/whisper.cpp`. В Rust crate также есть feature `vulkan`. Следовательно, сейчас поддерживаются две реализации протокола с риском расхождения отмены, лимитов и ошибок.

Историческая причина выбора C++ не подтверждена отдельным воспроизводимым сравнением. Предположение о конфликте ggml, меньшем размере или большей скорости не является установленным фактом.

## Решение

Сохранить существующий C++/CMake-путь до отдельного исследования ARC-08. Он явно выбирает Vulkan-сборку закреплённого whisper.cpp и не смешивает её артефакты с CUDA. Поставляемый бинарник обязан пройти тот же protocol handshake и требования к frame limits, operation IDs и отмене.

Этот ADR фиксирует текущее состояние и причину осторожного сохранения работающего build path. Он не объявляет C++ предпочтительнее Rust и не закрывает ARC-08.

## Альтернативы

- Собирать Vulkan из `fono-stt-worker --features vulkan`, удалить дублирование после проверки эквивалентности.
- Оставить две реализации надолго, закрепив общий исполняемый набор contract tests и обоснованный бюджет сопровождения.

## Последствия

До унификации требуется отдельно проверять оба бинарника. Для решения ARC-08 нужно собрать Rust-вариант, сравнить протокол, отмену, ошибки, зависимости, размер и реальные CPU/GPU-прогоны на одном whisper.cpp/model revision. После этого ADR будет заменён результатом измерений, а не догадкой о прошлом выборе.

Код: `scripts/build-stt-workers.ps1`, `src-tauri/crates/fono-stt-vulkan-worker`, `src-tauri/crates/fono-stt-worker/Cargo.toml`. Контракт: [STT backend-ы](../MULTI_BACKEND_ARCHITECTURE.md).
