# Архитектурные решения Fono

ADR объясняет, какую задачу решает выбранный подход и чем за него приходится платить. Это описание решения в коде, а не отчёт о пользовательской приёмке. Её результаты находятся в [STATUS](../STATUS.md), команды проверок — в [testing](../testing.md).

| ADR                                  | Решение                                                            | Статус                               |
| ------------------------------------ | ------------------------------------------------------------------ | ------------------------------------ |
| [0001](0001-isolated-gpu-workers.md) | GPU-распознавание в отдельных процессах                            | Принято                              |
| [0002](0002-vulkan-cpp-worker.md)    | Сохранить текущую C++/CMake-сборку Vulkan до проверки альтернативы | Временное решение; ARC-08 открыт     |
| [0003](0003-wake-word-freeze.md)     | Заморозить WakeWord и отделить его от обычной диктовки             | Принято                              |
| [0004](0004-sqlite-history.md)       | SQLite и кэш истории в памяти                                      | Реализовано; Windows-приёмка открыта |

Новый ADR содержит контекст, решение, альтернативы, последствия и статус. При замене решения добавьте новый документ и связь с прежним: история причин полезнее переписанного задним числом объяснения.
