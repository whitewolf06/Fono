## Граница документации

В docs находятся только эти 12 постоянных Markdown-документов. При изменении функции обновляется существующее руководство. Планы, приоритеты, состояние задач, результаты конкретных проверок и история решений поддерживаются в Кворуме. Внешнему разработчику доступ к нему для использования руководств не нужен.

Временные материалы больших задач находятся в игнорируемой `.work/tasks/<task-key-or-slug>/`. После сохранения важных результатов в Кворуме и обновления руководств контекст завершённой задачи удаляется. Архивы, JSON-отчёты и промежуточные журналы в docs не добавляются; это проверяет npm run docs:check.
