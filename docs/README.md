## Голосовое ядро и отложенные эксперименты

[Голосовое ядро](fono-voice-reliability.md) описывает общие контракты, WAV replay и условия дальнейшей проверки. [Архитектура WakeWord](WAKE_WORD_ARCHITECTURE.md) сохраняет детали отключённого детектора.

WakeWord временно недоступен, режим «На лету» скрыт. Методики возврата этих функций не разрешают включать их в текущем приложении. Пользователь самостоятельно проверяет микрофон, hotkey, внешние поля, окна и установку; browser mock и unit tests подтверждают только свой уровень.
