## Статус, приёмка и история

- [STATUS](STATUS.md) — текущие возможности, подтверждённые проверки и открытые критерии.
- [Roadmap](roadmap.md) — оставшаяся работа по приоритетам.
- [QA](qa/README.md) — сценарии ручной проверки; наличие сценария не означает, что он пройден.
- [Выпуск 0.8.0](releases/0.8.0.md) — состав опубликованной сборки и ограничения.
- [Архив](archive/README.md) — отчёты FONO-47, PERF-04, эксперименты и JSON-снимки.

В корне `docs` храните действующие руководства и контракты. Причины архитектурных
решений добавляйте в `adr/`, сценарии — в `qa/`, сведения о выпусках — в
`releases/`. Завершённые этапы и датированные отчёты относятся к архиву.
Рабочие результаты новых прогонов сохраняйте в `build/`; перенос в Git требует
проверки происхождения данных и отсутствия личных записей.
