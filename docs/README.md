# Документация Fono

## Статус и приёмка

[STATUS](STATUS.md) содержит актуальный срез реализации, подтверждённые прогоны и оставшиеся проверки. [QA](qa/README.md) хранит сценарии ручной приёмки и экспериментальные методики. [Roadmap](roadmap.md) — дальнейшие задачи.

Отчёты этапов сохраняют результаты конкретной версии: [первый](improvement-stage-1.md), [второй](improvement-stage-2.md). Их числа не переносятся на последующие изменения автоматически. Исходный план и карточки Кворума доступны из этих отчётов.
