# Как пользоваться Fono

## Установка и первая диктовка

Скачайте установщик из [официальных выпусков для Windows x64](https://github.com/whitewolf06/fono/releases/latest). После установки выберите микрофон и загрузите локальную Whisper-модель. Для первого запуска можно выбрать CPU; GPU-ускорение зависит от доступного backend и драйвера.

Откройте нужное текстовое поле и нажмите настроенную горячую клавишу. В режиме удержания запись заканчивается при отпускании. В режиме повторного нажатия первая команда начинает запись, вторая завершает её. Распознавание выполняется после окончания записи.

Индикатор показывает состояние записи. При автоматической обработке завершение горячей клавишей вставляет результат в исходное поле. В режиме «По кнопке» сначала появляется исходный текст, а дальнейшее действие выбираете вы. Кнопка принятия в индикаторе оставляет текст для копирования. Если поле сменилось или стало недоступно, результат остаётся доступен для копирования. Отмена завершает текущую операцию.

WakeWord сейчас недоступен. Поэтапный режим «На лету» скрыт; обычная диктовка работает через горячую клавишу.

В «Настройки → Активация» для повторного нажатия можно включить завершение
по тишине через 2–10 секунд. По умолчанию оно выключено. Если продолжить
говорить во время отсчёта, пауза считается заново. Ручной Stop и отмена
остаются доступны; запись без речи не попадает в историю.

## Язык интерфейса

В «Настройки → Основные → Язык интерфейса» можно выбрать русский, English
или «Как в системе», затем сохранить. На русской Windows автоматический режим
показывает русский интерфейс, на остальных языках — английский. Ручной выбор
сохраняется после перезапуска. Язык распознавания и перевод задаются отдельно;
тексты записей и собственные инструкции при переключении не меняются.

## Обработка и перевод

Fono может сохранить исходную расшифровку, убрать запинки, оформить текст, выделить задачу или придать деловой стиль. Обработка и перевод включаются отдельно. Вариант «Без изменений» без перевода возвращает исходный текст и не вызывает LLM.

Для остальных вариантов настройте OpenAI-совместимое подключение. LM Studio позволяет обрабатывать текст локально; внешний сервер получает переданный ему текст. В режиме повторного нажатия быстрые настройки индикатора позволяют менять стиль и язык перевода во время записи. Последний выбор сохраняется для следующих диктовок.

Отдельная кнопка RU / EN / Авто задаёт язык распознавания речи для текущей записи
и следующих диктовок. Авто определяет язык по речи. Stop ждёт сохранения выбора;
при ошибке возвращается подтверждённый язык. Для GigaAM доступен только русский,
Parakeet определяет язык сама; ручной выбор предлагается для многоязычных моделей
Whisper. После начала распознавания язык менять нельзя.

Свои инструкции можно проверить на тексте в настройках обработки. Ошибка ИИ оставляет исходный текст для повтора, копирования или вставки. Результат сторонней модели стоит просмотреть перед использованием.

## Профили приложений

В «Настройки → Основные» можно задать стиль, перевод, язык распознавания и вставку
для отдельных приложений. Укажите имя exe без пути, например `code.exe`, и сохраните.
Параметры «Как в общих настройках» продолжают наследовать общий выбор.

Профиль выбирается при старте диктовки и показывается в индикаторе. Ручной выбор
в индикаторе имеет приоритет в этой сессии. Для остальных приложений действуют
общие настройки. Смена окна во время записи не переносит профиль и цель вставки;
при заблокированной вставке можно скопировать готовый текст.

Правила хранятся локально; для выбора используется только имя exe, без заголовков,
адресов страниц и содержимого окон. Отключение сохраняет профиль. Подробнее —
[реализация и ограничения](improvement-fono133.md).

## История, словарь и тренер

История сохраняет итоговый текст и параметры конкретной сессии. Срок хранения настраивается; по умолчанию это 365 дней. Последний результат текущей сессии остаётся в памяти и при выключенной истории.

Личный словарь выключен по умолчанию. После включения Whisper получает ограниченную подсказку с нужными написаниями, а точные замены целых слов и фраз исправляют готовый результат. Отдельный выключатель разрешает передавать написания в выбранное подключение LLM. Для облачного подключения список получает провайдер. Подробности и ограничения — [история, словарь и диагностика](fono-quality-enhancements.md).

Речевой тренер использует только сохранившиеся записи, для которых разрешена аналитика. Срок хранения аналитики задаётся отдельно. Если нужны полные 90 дней, оба срока должны покрывать этот период. Ранее удалённые записи восстановить нельзя. Подробнее — [речевой тренер](speech-trainer.md).

## Приватность

Распознавание Whisper выполняется на устройстве. Обработка или перевод отправляют текст в выбранное подключение только при включении соответствующей функции. Ключи подключений хранятся в Windows Credential Manager. История и аналитика управляются отдельно.

Технический отчёт создаётся локально по действию пользователя. Он не включает диктовки, ключи, инструкции, словарь и имена устройств. Сырые логи — отдельный источник: перед передачей их нужно просмотреть.

Локальный REST API доступен на loopback и требует bearer token. Не публикуйте этот порт наружу. Контракт и примеры — в [руководстве API](LOCAL_TRANSCRIPTION_API.md).

## Обновления и помощь

Пакет NVIDIA CUDA устанавливается отдельно в «Настройки → Аудио и распознавание».
Нажмите «Скачать и установить CUDA», чтобы загрузить пакет для текущей версии
Fono. Приложение проверит подпись и состав, затем применит его в простое.
Перед установкой завершите диктовку, задачи API и сохраните настройки.
Загрузку можно отменить. Если пакет для этой версии ещё не опубликован,
Fono покажет сообщение; Auto продолжит использовать Vulkan или процессор.

В browser mock эта кнопка только демонстрирует загрузку и отмену. Файлы на
компьютер не скачиваются, доступ к видеокарте не запрашивается.

Проверка обновлений доступна в приложении вручную. Необязательная автоматическая проверка включается в настройках и выполняется не чаще раза в сутки. Проверка канала не устанавливает обновление. Установка требует отдельного действия и завершения активных операций.

Известные ограничения и текущая приёмка — в [STATUS](STATUS.md). Для сообщения об ошибке приложите версию Fono, выбранные модель и ускорение, шаги и технический отчёт. Не добавляйте ключи, личные диктовки или содержимое чужих полей.
