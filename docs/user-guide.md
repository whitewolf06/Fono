# Как пользоваться Fono

## Установка и первая диктовка

Скачайте установщик из [официальных выпусков для Windows x64](https://github.com/whitewolf06/fono/releases/latest). После установки выберите микрофон и источник распознавания. Для работы на ПК загрузите локальную модель; для Fono Server настройте подключение по инструкции ниже. Локальную модель можно запустить на CPU; GPU-ускорение зависит от доступного backend и драйвера.

Откройте нужное текстовое поле и нажмите настроенную горячую клавишу. В режиме удержания запись заканчивается при отпускании. В режиме повторного нажатия первая команда начинает запись, вторая завершает её. Распознавание выполняется после окончания записи.

Индикатор показывает состояние записи. При автоматической обработке завершение горячей клавишей вставляет результат в исходное поле. В режиме «По кнопке» сначала появляется исходный текст, а дальнейшее действие выбираете вы. Кнопка принятия в индикаторе оставляет текст для копирования. Если поле сменилось или стало недоступно, результат остаётся доступен для копирования. Отмена завершает текущую операцию.

Кроме горячей клавиши доступно [пробуждение «Привет, Лира» beta](wake-lira.md).
Поэтапный режим «На лету» скрыт; распознавание выполняется после завершения записи.

В «Настройки → Кнопки и активация» для повторного нажатия можно включить завершение
по тишине через 2–10 секунд. По умолчанию оно выключено. Если продолжить
говорить во время отсчёта, пауза считается заново. Ручной Stop и отмена
остаются доступны; запись без речи не попадает в историю.

## Fono Server: распознавание на сервере

В настройках распознавания выберите **Fono Server**. Аудио будет отправляться
вашему серверу, а готовый текст вернётся в обычную диктовку, историю и вставку.
Модель работает на сервере и не занимает видеопамять ПК. Сам интерфейс Windows
может использовать GPU для отрисовки; это не загрузка модели распознавания.
Серверная модель не требует локальной копии. Обработка и перевод через LLM
по-прежнему настраиваются отдельно.

1. Получите у администратора адрес сервера и отдельный API-токен. Администратор
   создаёт токен в разделе приложений [веб-панели](server-clients.md).
   Ключ показывается один раз; потерянный ключ нужно отозвать и создать заново.
2. Выберите способ подключения. Для прямого подключения укажите HTTPS-адрес
   с доверенным сертификатом. Для **SSH** укажите сервер, пользователя,
   существующий файл личного ключа или используйте разблокированный SSH-агент.
   В Windows должен быть установлен OpenSSH Client. Обычно SSH использует порт
   `22`, а Fono Server — `17832`; уточните их у администратора.
3. Для SSH нажмите **Получить ключ сервера**, сверьте отпечаток с администратором
   и подтвердите доверие. **Отпечаток SSH-ключа не является API-токеном:**
   он подтверждает адресата, а токен разрешает обращаться к API. Копировать
   отпечаток в поле токена не нужно.
4. Введите API-токен и нажмите проверку подключения. Выберите установленную
   серверную модель из полученного списка. Проверка получает метаданные,
   не отправляет аудио и не сохраняет черновик.
5. Сохраните токен, затем настройки подключения. После сохранения Fono сам
   открывает SSH-канал при обращении к серверу; запускать команды или отдельный
   туннель не требуется. Токен хранится в Windows Credential Manager.

Прямой незашифрованный HTTP разрешён Windows-клиентом только для loopback,
например существующего локального туннеля. Адрес `http://` в локальной сети
для этого подключения не подходит. Ошибки сертификата и изменившийся SSH-ключ
не обходятся автоматически. Выбор моделей в клиенте не скачивает и не удаляет
модели на сервере: это делает администратор.

Если сервер недоступен, Fono показывает состояние и сохраняет запись для
явного повтора, локального распознавания или отмены в пределах доступного
времени. Политика локального резерва выбирается отдельно. Для резерва нужна
установленная локальная модель; при его использовании модель загружается на
ПК и распознаёт на CPU. Без настроенного резерва перехода на локальную модель
не происходит. Повтор после ошибки не должен приводить к повторной вставке.

Чтобы вернуться к локальному распознаванию, завершите текущую диктовку и
переключите источник. Локальные параметры модели и ускорения сохраняются.
Фактический источник, модель и время обработки видны в деталях новой записи
истории. Сценарии приёмки находятся в [проверке Windows и сервера](qa/remote-stt.md).

## Язык интерфейса

В «Настройки → Основные → Язык интерфейса» можно выбрать русский, English
или «Как в системе», затем сохранить. На русской Windows автоматический режим
показывает русский интерфейс, на остальных языках — английский. Ручной выбор
сохраняется после перезапуска. Язык распознавания и перевод задаются отдельно;
тексты записей и собственные инструкции при переключении не меняются.

## Обработка и перевод

Fono может сохранить исходную расшифровку, убрать запинки, оформить текст, выделить задачу или придать деловой стиль. Обработка и перевод включаются отдельно. Вариант «Без изменений» без перевода возвращает исходный текст и не вызывает LLM.

Для остальных вариантов настройте OpenAI-совместимое подключение. Если настройка
подключения не завершена, Fono пропускает дополнительную обработку и перевод:
обычная диктовка продолжает работать с исходной расшифровкой. Приложение показывает,
что подключение ещё нужно настроить.

LM Studio позволяет обрабатывать текст локально; внешний сервер получает
переданный ему текст. В режиме повторного нажатия быстрые настройки индикатора
позволяют менять стиль и язык перевода во время записи. Последний выбор
сохраняется для следующих диктовок.

Отдельная кнопка RU / EN / Авто задаёт язык распознавания речи для текущей записи
и следующих диктовок. Авто определяет язык по речи. Stop ждёт сохранения выбора;
при ошибке возвращается подтверждённый язык. Для GigaAM доступен только русский,
Parakeet определяет язык сама; ручной выбор предлагается для многоязычных моделей
Whisper. После начала распознавания язык менять нельзя.

Свои инструкции можно проверить на тексте в настройках обработки. Ошибка ИИ оставляет исходный текст для повтора, копирования или вставки. Результат сторонней модели стоит просмотреть перед использованием.

## Профили приложений

В «Настройки → Основные» можно задать стиль, перевод, язык распознавания и вставку
для отдельных приложений. Укажите имя exe без пути, например `code.exe`, и сохраните.
Параметры «Как в общих настройках» продолжают наследовать общий выбор.

Профиль выбирается при старте диктовки и показывается в индикаторе. Ручной выбор
в индикаторе имеет приоритет в этой сессии. Для остальных приложений действуют
общие настройки. Смена окна во время записи не переносит профиль и цель вставки;
при заблокированной вставке можно скопировать готовый текст.

Правила хранятся локально; для выбора используется только имя exe, без заголовков,
адресов страниц и содержимого окон. Отключение сохраняет профиль.

## Настройки и пробуждение

В каждом разделе основные параметры видны сразу. Редкие параметры находятся в
«Дополнительно»; поиск помогает найти настройку независимо от раскрытого блока.

Лира включается на главной в карточке «Пробуждение» или в настройках активации.
Дождитесь «Слушаю», произнесите «Привет, Лира» и начинайте диктовать после сигнала
готовности или появления индикатора. После завершения сессии детектор возвращается
к ожиданию. Это beta: заметная задержка и проверка на других голосах остаются
открытыми. Старый мастер собственной wake-фразы и форма dev-записей в release
недоступны. Подробности — в [руководстве Лиры](wake-lira.md).

## История, словарь и тренер

В «Настройки → История и приватность» можно отдельно включить сохранение приложения для вставки. Fono запишет имя exe и исход попытки, без заголовков окон, сайтов и содержимого полей. В истории появятся метки, фильтр и сводка попыток за период; попытка не означает подтверждённую доставку текста. Настройка выключена по умолчанию. Выключение скрывает метки и останавливает сбор для новых диктовок; сохранённый контекст можно удалить у одной записи или у всех, сохранив тексты и варианты LLM.

История сохраняет итоговый текст и параметры конкретной сессии. Срок хранения настраивается; по умолчанию это 365 дней. Последний результат текущей сессии остаётся в памяти и при выключенной истории.

В деталях записи можно получить отдельный вариант от LLM. Выбери исходный или итоговый текст, один из пяти стилей и настроенное подключение, затем нажми «Показать вариант от LLM». Для облачного подключения Fono попросит подтвердить отправку выбранного текста. Оригинал и итог диктовки останутся прежними. Сохранённый вариант можно скопировать или удалить отдельно; повтор с теми же настройками использует кэш. Варианты хранятся вместе с записью. Подробности — [ручная редактура истории](qa/history-rewrite.md).

Личный словарь выключен по умолчанию. После включения Whisper получает ограниченную подсказку с нужными написаниями, а точные замены целых слов и фраз исправляют готовый результат. Отдельный выключатель разрешает передавать написания в выбранное подключение LLM. Для облачного подключения список получает провайдер. Подробности и ограничения — [история, словарь и диагностика](fono-quality-enhancements.md).

Речевой тренер использует только сохранившиеся записи, для которых разрешена аналитика. Срок хранения аналитики задаётся отдельно. Если нужны полные 90 дней, оба срока должны покрывать этот период. Ранее удалённые записи восстановить нельзя. Подробнее — [речевой тренер](speech-trainer.md).

## Приватность

При локальном источнике распознавание выполняется на ПК. При выборе Fono Server
аудио отправляется настроенному серверу; его адрес и модель видны в настройках.
Обработка или перевод отправляют текст в выбранное LLM-подключение только при
включении соответствующей функции. Ключи подключений хранятся в Windows Credential
Manager. История и аналитика управляются отдельно. Серверная веб-панель не является
архивом диктовок; отдельные ключи приложений управляют доступом, а не сбором текстов.

Технический отчёт создаётся локально по действию пользователя. Он не включает диктовки, ключи, инструкции, словарь и имена устройств. Сырые логи — отдельный источник: перед передачей их нужно просмотреть.

Локальный REST API доступен на loopback и требует bearer token. Не публикуйте этот порт наружу. Контракт и примеры — в [руководстве API](LOCAL_TRANSCRIPTION_API.md).

## Обновления и помощь

Пакет NVIDIA CUDA устанавливается отдельно в «Настройки → Аудио и распознавание».
Нажмите «Скачать и установить CUDA», чтобы загрузить пакет для текущей версии
Fono. Приложение проверит подпись и состав, затем применит его в простое.
Перед установкой завершите диктовку, задачи API и сохраните настройки.
Загрузку можно отменить. Если пакет для этой версии ещё не опубликован,
Fono покажет сообщение; Auto продолжит использовать Vulkan или процессор.

В browser mock эта кнопка только демонстрирует загрузку и отмену. Файлы на
компьютер не скачиваются, доступ к видеокарте не запрашивается.

Проверка обновлений доступна в приложении вручную. Необязательная автоматическая проверка включается в настройках и выполняется не чаще раза в сутки. Проверка канала не устанавливает обновление. Установка требует отдельного действия и завершения активных операций.

Известные ограничения и текущая приёмка — в [STATUS](STATUS.md). Для сообщения об ошибке приложите версию Fono, выбранные модель и ускорение, шаги и технический отчёт. Не добавляйте ключи, личные диктовки или содержимое чужих полей.
