# Fono 0.8.0 — кандидат в релиз

Выпуск готовится локально. Установка, проверка установленной сборки и публикация выполняются отдельно. Кворум на время этой работы приостановлен владельцем.

## Что входит

- Пробуждение «Привет, Лира» с меткой **Бета**. После запуска Fono оно выключено; включается на главной или в настройках активации. Распознавание работает локально, отдельный Python устанавливать не нужно.
- Проверенная схема детектора из v0.7.81/v0.7.83, звук готовности и очистка фразы «Привет, Лира / Лера / Ира» перед вставкой. Эксперимент ускорения v0.7.82 в выпуск не входит.
- Основные параметры в каждом разделе настроек, второстепенные — в «Дополнительно». Инструменты записи и проверки тестовых образцов остаются только в dev.
- Восстановление интерфейса после сна, исправления вставки при изображении в буфере и пропуск дополнительной обработки, если подключение ещё не настроено.
- Накопленные изменения истории, профилей приложений, словаря и локальной обработки текста. Уже пройденные проверки основной диктовки повторять целиком не требуется.

## Поставка Лиры

Windows x64: изолированный CPython 3.12.14, NumPy 1.26.4, ONNX Runtime 1.23.2 CPU, точные модели CNN и T-one. Пакет находится в `resources/lira` и входит в NSIS/MSI; личных записей и обучающего корпуса там нет.

Зависимости и исходники детектора закреплены по SHA256. Сборка проверяет закрытый список файлов; при включении Лиры приложение повторно проверяет этот список и встроенный хэш manifest. Пути разработчика, системный Python и `PYTHONPATH` в release не используются. Повреждённый пакет останавливает включение до открытия микрофона.

Подготовка: `npm run release`. Для подписанного updater используется `scripts/update-release-config.mjs` и существующий ключ канала. Скрипт не публикует файлы. Онлайн-загрузчик собирается отдельно через `npm run build:setup` и обращается к опубликованному каналу; до публикации 0.8.0 он не выдаёт этот локальный кандидат.

Для воспроизводимой сборки нужен Python 3.12+ и закреплённый Visual C++ x64 redistributable из build SDK: каталог 14.44.35112, файлы 14.44.35211.0. Точные хэши — в [dependencies.json](../../tools/wake-release/dependencies.json). Смена SDK с другими файлами требует обновления lock и проверки пакета; автоматической подмены DLL нет.

Источник переносимого Python — [Astral](https://github.com/astral-sh/python-build-standalone/releases/tag/20260924); источник T-one и инструкция по модели — [sherpa-onnx](https://k2-fsa.github.io/sherpa/onnx/pretrained_models/online-ctc/t-one-ctc-models.html). Лицензии и атрибуция включены в `THIRD-PARTY-NOTICES.txt` пакета.

## Что остаётся открытым

- Заметная задержка пробуждения и два известных пропуска в dev-наборе. Короткий replay не подтверждает качество на других голосах и длительной обычной речи. Порог и критерии качества не ослаблены.
- Строгий критерий PERF-04, расширенные проверки CPU/CUDA/Vulkan, памяти, простоя и устройств остаются отдельными хвостами. Их статус не меняется из-за сборки релиза.
- Чистая Windows ранее отложена владельцем. Локальные тесты не заменяют установку, UAC, работу WebView2 и проверку обновления установленного приложения.
- Публикация установщика, подписанного `latest.json` и CUDA-пакета ещё не выполнена. Подпись updater и Windows Authenticode — разные подписи.

## Короткая приёмка кандидата

1. Установить NSIS 0.8.0 вручную: окно открывается, версия 0.8.0, прежние настройки и история на месте.
2. Один раз продиктовать через горячую клавишу во внешнее поле. Проверить вставку и закрытие индикатора.
3. Включить «Пробуждение — Бета», дождаться «Слушаю», обратиться к Лире три раза подряд. Начинать диктовку после звука готовности или появления индикатора; фраза пробуждения не должна попадать в результат.
4. Выключить пробуждение, перезапустить Fono: оно остаётся выключенным. В диагностике нет формы тестовых записей.
5. Увести компьютер в сон и вернуть: интерфейс восстанавливается. Обновление установленной версии проверить отдельно после согласования и появления подписанного пакета в канале.

Фактические размеры, SHA256, подписи и результаты сборки сохраняются рядом с локальными артефактами в `build/releases/0.8.0/`. Этот документ не объявляет установку или ручную приёмку выполненными.
