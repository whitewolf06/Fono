# Fono 0.9.1 — Vulkan по умолчанию

Кандидат после подготовленного [0.9.0](0.9.0.md). Публикация и обновление
пользовательских установок выполняются отдельно.

## Состав

- Auto в Windows использует Vulkan на подходящей дискретной GPU; без неё — CPU.
- Базовый установщик содержит Vulkan worker и встроенный CPU. CUDA устанавливается
  отдельным подписанным пакетом и выбирается явно; установка пакета не меняет Auto.
- Основной Fono Server для Ubuntu поставляется как Vulkan + CPU. Дополнительный
  CUDA Docker-образ использует тот же API v2, формат моделей и ключей доступа.
- Vulkan проверяет физическую GPU, закрепляет её индекс и прогревает классический
  и оконный графы до готовности модели. Кэш шейдеров сохраняется между запусками.
- Диагностика, метаданные и очередь сервера учитывают Vulkan как отдельный backend.
  Бюджет процесса не выдаётся за глобальную свободную видеопамять.

Серверное распознавание Windows-клиента, подключение из интерфейса, веб-панель
и ключи приложений сохраняются. Лира остаётся beta; скрытые экспериментальные
режимы не включаются.

## Проверка и развёртывание

Результаты и ограничения — [проверка Vulkan](../qa/vulkan-default.md).
Команды подготовки Windows CUDA-пакета — [руководство](../cuda-package-build.md),
образы и конфигурация сервера — [Fono Server](../server.md).

Windows GPU-замеры отложены до закрытия игры. Чистая установка Windows и аппаратная
матрица AMD/Intel остаются отдельной приёмкой. Рабочий сервер Kari этим кандидатом
не обновлён; его данные и ключи сохраняются.
